## 5 分钟地图

反馈双稳态 → S-R 锁存器 → D 锁存器 → 边沿 D 触发器 → 异步控制/使能 → J-K、T → Verilog。

## 题型路由

| 题目信号 | 第一动作 |
|---|---|
| S-R 门图 | 判 NOR/NAND 与高低有效 |
| D 波形 | 圈有效边沿和建立/保持窗口 |
| 异步复位 | 先处理，不等时钟 |
| 触发器转换 | 写目标 $Q\to Q^{+}$ |
| 计数翻转 | 想到 T 或 J-K 的翻转条件 |
| Verilog | 查敏感表、优先级和非阻塞赋值 |

## 第一动作

先写“器件类型、有效边沿、异步端、优先级”。这四项确定后再画 $Q$。

## 最小自测

1. 问：D 锁存器与 D 触发器的关键区别？  
   答案要点：锁存器在有效电平期间透明，触发器只在边沿采样。
2. 问：NOR 型 S-R 的禁止输入是什么？  
   答案要点：$S=R=1$。
3. 问：$T=1$ 时 T 触发器怎样更新？  
   答案要点：翻转，$Q^{+}=\overline Q$。
4. 问：建立/保持违例后能否确定输出？  
   答案要点：不能保证，可能亚稳或不可预知。
5. 问：时序 `always` 块为何通常用非阻塞赋值？  
   答案要点：让多个寄存器基于边沿前状态并行计算、统一更新。

## 问题入口

把状态表、波形或 Verilog 发给 tutor，让 tutor 先核对有效边沿和优先级，再逐边沿更新状态。
