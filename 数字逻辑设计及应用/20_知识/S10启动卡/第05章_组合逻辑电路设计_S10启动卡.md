## 5 分钟地图

规格 → 真值表 → 化简 → 门/MSI 实现 → 险象与延迟检查。常用模块：编码器、译码器、MUX、比较器、校验器和加法器。

## 题型路由

| 题目信号 | 第一动作 |
|---|---|
| 分析门图 | 标中间节点 |
| 文字设计 | 定义每个变量的 0/1 |
| 险象 | 找原、反双路径和未共同覆盖相邻格 |
| 译码器实现 | 写输出为 1 的最小项 |
| MUX 实现 | 选择变量后列余函数 |
| 加法器 | 先区分本位输入进位与输出进位 |
| 延迟 | 找关键路径 |

## 第一动作

先把题目统一成真值表。器件只是实现方式；真值表没定清之前，不要直接接译码器或 MUX。

## 最小自测

1. 问：组合逻辑输出是否依赖过去状态？  
   答案要点：不依赖，只由当前输入决定。
2. 问：普通编码器为何不能默认处理多个有效输入？  
   答案要点：其基本假设是一时刻只有一路有效，多路时输出不唯一。
3. 问：4 选 1 MUX 实现三变量函数时，数据端可能接什么？  
   答案要点：0、1、剩余变量或其反变量。
4. 问：静态 1 险象是什么？  
   答案要点：输出本应保持 1，却因路径延迟短暂降为 0。
5. 问：行波进位为何慢？  
   答案要点：高位必须等待低位进位逐级传播。

## 问题入口

把规格、真值表或门图发给 tutor，让 tutor 先检查逻辑抽象，再一起选择器件并核验险象和延迟。
