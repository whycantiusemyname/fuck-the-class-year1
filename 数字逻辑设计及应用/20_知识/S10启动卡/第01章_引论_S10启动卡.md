# 第1章 引论 S10 启动卡

> 这是进入 S10 问答/做题前的启动卡，不替代 `主干讲解.md`。
> 完全没学过本章时，先读主干讲解；读过但准备做题时，再读这份。

## 5 分钟地图

物理量 → 传感器/模拟前端 → ADC → 数字处理与存储 → DAC/驱动 → 执行机构。数字处理内部再分为“只看当前输入”的组合逻辑和“还记住过去”的时序逻辑。

## 题型路由

| 题目信号 | 去哪里想 |
|---|---|
| 位数、量化档位 | 先写 $2^n$ 个码字 |
| 组合还是时序 | 问是否需要过去状态 |
| 处理器还是 FPGA | 比较顺序执行、硬件并行和修改成本 |
| 系统框图 | 先划模拟域、数字域和执行端 |
| 设计过程 | 从可验证规格开始，不从器件型号开始 |

## 第一动作

拿到情境题先圈出输入、输出、是否要记忆以及允许延迟，再决定需要 ADC/DAC、组合逻辑、状态存储或哪种实现平台。

## 最小自测

1. 问：4 位二进制能表示多少个不同码字？  
   答案要点：$2^4=16$ 个。
2. 问：按钮按一次后灯一直亮，为什么不是纯组合逻辑？  
   答案要点：按钮释放后仍需保存“已按下”状态。
3. 问：FPGA 与处理器运行程序的核心差异是什么？  
   答案要点：FPGA 综合成并行硬件结构，处理器通常按指令序列执行。
4. 问：数字信号为什么仍要考虑噪声？  
   答案要点：逻辑 0/1 由实际电压区间承载，噪声跨过判决边界会造成错误。

## 问题入口

把一个具体系统发给 tutor，让 tutor 先追问输入输出、量化精度、记忆需求和速度约束，再帮你选结构。
