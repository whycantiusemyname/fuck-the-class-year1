# 第4章 逻辑门电路 S10 启动卡

> 这是进入 S10 问答/做题前的启动卡，不替代 `主干讲解.md`。

## 5 分钟地图

MOS 开关 → CMOS 上拉/下拉 → 门功能 → 合法电平与噪声容限 → 扇出 → 延迟和功耗 → 逻辑族接口。

## 题型路由

| 题目信号 | 第一动作 |
|---|---|
| 画 CMOS 门 | 先画 NMOS 下拉条件，再取 PMOS 对偶 |
| 噪声容限 | 用保证的最小值/最大值 |
| 扇出 | 高态、低态分别算 |
| TTL 接 CMOS | 先验电压，再验电流 |
| 开漏上拉 | 同时看压降、电流、$RC$ |
| 门链延迟 | 标每一级输出转换方向 |

## 第一动作

先把题目分成逻辑、静态电气、动态时序三层。题目问哪一层，就用哪一层的参数，别拿真值表代替接口核验。

## 最小自测

1. 问：CMOS NAND 的 NMOS 网络怎样连接？  
   答案要点：串联；只有所有输入为 1 时下拉。
2. 问：高阻态是否等于逻辑 0？  
   答案要点：不等于，它表示输出近似与总线断开。
3. 问：接口为什么既要验电压又要验电流？  
   答案要点：电压决定能否被识别，电流决定能否在负载下维持该电平。
4. 问：CMOS 未用输入为什么不能悬空？  
   答案要点：悬浮可能落入阈值区，导致不确定输出和直通电流。

## 问题入口

把门电路或数据手册参数发给 tutor，让 tutor 按“逻辑—电压—电流—延迟”逐层核验。
