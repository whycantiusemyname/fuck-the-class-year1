## 5 分钟地图

数字码 → 位权网络 → DAC 模拟量；模拟量 → 采样保持 → 量化比较 → ADC 码字。

## 题型路由

| 题目信号 | 第一动作 |
|---|---|
| DAC 输出 | 标 MSB/LSB 权重和参考极性 |
| 分辨率 | 确认端点口径 |
| 采样率 | 找 $f_{\max}$，验 $f_s\ge2f_{\max}$ |
| ADC 码 | 求 FSR/$2^n$ |
| SAR | 从 MSB 开始试探 |
| 架构比较 | 比速度、硬件量、精度/抗扰 |
| 串行时序 | 标有效电平和采样边沿 |

## 第一动作

先写“位数、满量程、参考极性、编码、速度要求”。没有这五项，不要直接套公式。

## 最小自测

1. 问：8 位 ADC 有多少个量化区间？  
   答案要点：$2^8=256$ 个。
2. 问：最高频率 10 kHz 的信号理论最低采样率？  
   答案要点：20 kHz；工程上通常还要留滤波余量。
3. 问：SAR 第一位先试哪一位？  
   答案要点：最高有效位。
4. 问：Flash ADC 为什么快但规模大？  
   答案要点：多个阈值并行比较，比较器数量随位数指数增加。
5. 问：双积分 ADC 的主要优势？  
   答案要点：精度和抗周期噪声较好，但转换慢。
