# 第8章 半导体存储器与可编程逻辑器件：从码字阵列到可配置硬件

## 这一章抓什么

本章把“存一位”扩展为“按地址存取大量字”，再把规则化阵列扩展成可编程逻辑。存储器关注地址、字长、容量、读写与数据保持；CPLD/FPGA 关注逻辑资源、互连、时钟和开发流程。二者共同体现规则结构的力量：大量重复单元配合可选择连接，可以比逐门定制更容易扩展和验证。

不要把 ROM、RAM、CPLD、FPGA 只当器件名。做题应先抓组织结构：地址如何选中一个字，数据如何读出或写入，逻辑函数怎样映射为存储内容或乘积项，设计如何经过综合、布局布线和时序验证落到器件。

## 先建立整体直觉

若有 $n$ 根地址线，就可以选择 $2^n$ 个地址；每个地址存 $m$ 位，则存储器组织写成：

$$
2^n\times m
$$

它表示“字数 × 每字位数”，总位容量为 $2^nm$。地址译码器一次选中一个字，数据端口把该字送出或接收写入数据，片选和读写控制决定器件是否响应。

ROM 还可以看成一张硬件化真值表：地址线是输入变量，存储的每一位是一个输出函数值。把函数所有输入组合对应的输出码预先写入 ROM，任意组合逻辑都能通过查表实现。由此可以看见存储器和逻辑器件之间并非割裂，而是“规则阵列 + 可配置内容”的两种用法。

## 本章怎么串起来

本章主线是：

存储器组织与地址译码 → ROM/PROM/EPROM → RAM、SRAM/DRAM → 用 ROM 实现逻辑 → 容量扩展 → CPLD 的乘积项与宏单元 → FPGA 的逻辑块、I/O、存储和互连 → 可编程逻辑开发流程。

先理解数据如何被选中，再理解逻辑资源如何被编程和连接；最后把抽象设计转化为器件配置。

## 分节主干

### 容量、速度、成本形成存储层次权衡

理想存储器希望容量大、速度快、单位成本低且掉电不丢数据，但这些目标难以同时做到。设计时要明确需要保存多少字、每字多少位、访问时间、读写频率和掉电保持要求。

容量写法中的“字”和“位”不能混淆。例如 $1\text{K}\times8$ 表示 1024 个字、每字 8 位，总容量为 8192 位；它需要 10 根地址线和 8 根数据线。地址线增加 1 根会使字数翻倍，数据线增加 1 根只使每字多 1 位。

### ROM 以固定或可写阵列保存内容

ROM 在正常工作中主要执行读取，掉电后内容保留。掩膜 ROM 在制造阶段确定内容；PROM 可由用户一次编程；EPROM 可通过特定方式擦除后重写。具体编程与擦除特性取决于器件，不能只凭“ROM”一词推断是否永远不能修改。

ROM 的结构包含地址译码、存储矩阵和输出缓冲。教材的二极管矩阵示例用连接是否存在表示 1 或 0；实际器件实现不同，但“地址选择一行、该行连接决定输出字”的逻辑相同。输出使能无效时常进入高阻，以便多个存储器共享数据总线。

### 用 ROM 实现组合逻辑就是写入真值表

若有 $n$ 个输入、$m$ 个输出，可选择至少 $2^n\times m$ 的 ROM。把输入变量接地址线，对每个地址写入相应的 $m$ 位输出码。设计步骤是：

输入编码 → 列完整真值表 → 把输入组合当地址 → 把输出向量写成该地址内容 → 连接使能和输出。

这种实现不要求先化简每个函数，适合多输出、规则复杂或后续需改内容的逻辑；代价是可能使用大量未充分利用的存储单元。题目要求“用 ROM 实现”时，重点是地址—内容表，不要仍停留在门级化简。

### RAM 支持读写，SRAM 与 DRAM 的存储机制不同

RAM 可按地址随机访问并读写，通常易失。SRAM 单元用反馈结构保存状态，只要供电存在就不需周期刷新，访问快但单元占面积较大。DRAM 用电容电荷表示数据，单元密度高，但电荷会泄漏，需要周期刷新，读取过程也需要相应恢复。

读写时序要满足地址稳定、片选、读写控制、数据建立/保持和访问时间。不能只看逻辑功能表；若写使能脉冲太短、地址过早变化或总线驱动冲突，存储内容可能错误。

### 位扩展与字扩展解决不同容量缺口

若器件字数够但每字位数不足，把多片的地址和控制线并联，每片承担数据字的一部分，这叫位扩展。例如两片 $1\text{K}\times4$ 可组成 $1\text{K}\times8$。

若每字位数够但字数不足，把高位地址送入译码器产生各片片选，低位地址并联到所有芯片，数据总线共享，这叫字扩展。字、位同时不足时两种扩展组合使用。画图前应先把目标组织除以单片组织，分别求横向位数组和纵向字数组。

### CPLD 以可编程乘积项和宏单元组织逻辑

CPLD 常把输入送入可编程互连阵列，再进入宏单元。宏单元能够形成乘积项、组合或寄存输出，并通过 I/O 控制连接引脚；全局时钟、清零和输出使能网络为大量单元提供较一致的控制。

教材展示的宏单元并不是一只“大门”。局部乘积项不够时，可以从相邻宏单元借用或共享乘积项；组合结果也可送到内部的隐埋触发器而不占用外部引脚；输出触发器还可按配置承担不同触发功能。审结构图时应沿“互连阵列 → 乘积项 → 组合汇总 → 可选寄存 → 输出使能/I/O 或反馈”逐段追踪，并标出哪一步受器件资源上限约束。

把逻辑映射到这类结构时，应先求适合的积之和式，统计每个输出需要的乘积项和输入文字数，再检查器件宏单元与乘积项限制。逻辑上可化简的函数不一定能直接装入特定资源，需要共享、分解或更换器件。

CPLD 的价值不只是“门多”，还在于互连与延迟较规则，适合中等规模控制、译码和状态逻辑。具体配置是否掉电保持取决于器件工艺，不能一概而论。

### FPGA 以查找表、寄存器和可编程互连构成更大系统

FPGA 通常包含 I/O 块、可配置逻辑块、时钟管理、块 RAM、丰富互连以及某些嵌入式功能单元或硬核。逻辑块中的查找表可以实现小规模组合函数，旁边的寄存器实现时序逻辑；可编程互连把大量单元组织成数据通路和控制器。

FPGA 的“可编程”主要是配置硬件结构。综合工具把 HDL 运算、条件和状态机映射为查找表、触发器、存储与互连，布局布线决定这些资源的物理位置和连线，因此同一逻辑在不同布局下可能有不同时序结果。

CPLD 与 FPGA 的比较应围绕规模、资源形态、互连、时序可预测性、存储和适用结构展开，而不是简单说一个“低级”、一个“高级”。

### IP 核与开发流程把设计复用和验证纳入工程

教材把可编程 IP 分为软核、固核和硬核：软核通常以可综合描述交付，移植性较强；固核提供较固定的网表或实现约束；硬核是芯片内已实现的专用单元。抽象程度越低，性能可预测性往往越强，但移植和修改空间越小。

完整开发链为：

功能定义/器件选型 → 设计输入 → 功能仿真 → 综合优化 → 综合后仿真 → 实现与布局布线 → 时序仿真 → 板级验证 → 编程与调试。

功能仿真检查逻辑意图，综合检查能否映射为硬件，布局布线后时序验证检查真实路径是否满足时钟约束，板级验证再覆盖电源、时钟、I/O 与外设。任何一个阶段通过都不能替代后续阶段。

## 解题流程

存储容量题先把目标组织和单片组织都写成“字数 × 位数”。目标字长除以单片字长得到位扩展因子，目标字数除以单片字数得到字扩展因子；确定所需芯片阵列后，再让高位地址经译码器产生片选，低位地址和数据线按字扩展或位扩展的职责连接。这样计算和接线使用的是同一套组织关系，不容易把横向扩位与纵向扩字画反。

ROM 实现逻辑：

1. $n$ 个输入接地址线。
2. $m$ 个输出确定每字 $m$ 位。
3. 按真值表写地址—内容表。

PLD/FPGA 题：

1. 先识别组合、寄存、存储和 I/O 资源需求。
2. 再选择器件结构和输入形式。
3. 区分功能仿真、综合、布局布线后时序和板级验证。

## 易错点

- 把存储器总位容量与字数、字长混为一谈。
- 位扩展时错误译码高位地址，或字扩展时把数据线分开而不是共享。
- 用 ROM 实现函数仍只画门图，没有给地址—内容表。
- 认为所有 ROM 都不可改、所有可编程器件都掉电保持。
- 把 SRAM 的“静态”理解为不需要供电。
- 忽略 DRAM 刷新和读写时序。
- 认为 HDL 功能仿真通过就代表布局布线后时序一定通过。
- 比较 CPLD/FPGA 时只按容量大小下结论，忽略资源形态与互连。

## 进入 S10 的问题入口

- 计算一个给定存储器的地址线、数据线和总容量。
- 用若干小容量芯片扩展成目标组织并画连接。
- 用 ROM 实现两个输出函数，写出地址—内容表。
- 判断一项设计更适合 CPLD 还是 FPGA，并给出资源理由。
