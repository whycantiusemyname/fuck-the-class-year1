# 第1章 引论：从现实信号到可设计的数字系统

## 这一章抓什么

这一章不是在罗列数字技术的优点，而是在回答一个贯穿全书的问题：现实世界中的连续信息，怎样变成可以由逻辑电路可靠处理的离散状态，又怎样从门电路逐步组织成完整系统。后面学习二进制、逻辑代数、组合电路、触发器和状态机时，都应把它们放回这条链上理解。

数字系统设计的对象不是孤立的“0”和“1”，而是具有明确输入、处理规则、内部状态和输出目标的系统。组合逻辑只由当前输入决定输出，时序逻辑还要保存过去状态；专用硬件、微处理器程序和可编程逻辑器件只是不同实现路径，最终都要满足功能、速度、容量、可靠性与成本约束。

## 先建立整体直觉

真实世界中的温度、声音、压力和位置通常连续变化。传感器先把物理量转换成电信号，模拟前端再完成放大、滤波或电平调整，模数转换器把连续幅值映射到有限个二进制码。数字系统在码字上进行判断、计算、存储或控制；若要驱动扬声器、电机等模拟对象，还需经过数模转换和功率放大。

因此，一条典型链路是：

物理量 → 传感器与模拟预处理 → 采样、量化和编码 → 数字处理或存储 → 数模转换与执行机构 → 物理输出。

如果把输出结果再送回输入端比较，就形成反馈控制闭环。数字部分的可靠并不意味着整个系统没有误差；采样频率、量化位数、传感器噪声和执行器能力都会影响最终结果。

教材用两位编码表示 $0\text{ V}$ 到 $3\text{ V}$ 的模拟幅值。两位只有 $2^2=4$ 个码字，只能把连续幅值分成四档；位数增加到 $n$ 位后可区分 $2^n$ 个量化区间，恢复波形会更接近原信号，但数据量、转换器复杂度和处理成本也随之增加。数字化的实质不是让连续信息“原样消失”，而是用允许的精度换取可复制、可运算、可存储和较强抗干扰能力。

另一个关键直觉是：数字信号并不是脱离物理世界的抽象符号。电路中的高、低电平仍然是模拟电压，脉冲边沿仍有上升时间、延迟和噪声。只有当系统规定某个电压范围代表逻辑 0、另一个范围代表逻辑 1，并留出噪声容限后，这些模拟波形才承载数字意义。后面分析门电路时，逻辑功能与电气特性必须同时成立。

## 本章怎么串起来

本章的主线可以写成：

现实连续信息 → 二值编码 → 组合处理与状态存储 → 器件和实现方式选择 → 分层设计、验证与迭代。

前两步解释数字系统为何需要二进制表达；中间两步把“逻辑功能”落实到门、寄存器、处理器或 FPGA；最后一步提醒我们，系统设计不是把模块一次拼完，而是在规格、实现、验证和代价之间反复收敛。

## 分节主干

### 从模拟信号到数字信号

模拟信号在时间和幅值上通常连续，数字信号在系统规定的时刻与取值集合上离散。数字化一般包含采样、量化和编码三个动作：采样决定“何时看”，量化决定“分成多少档”，编码决定“每一档用什么比特串表示”。本章只建立概念框架，具体采样与量化条件会在第9章展开。

数字传输的优势来自判决。只要接收端看到的电平仍落在合法的 0 或 1 区间，就可以重新生成标准电平，而不必逐点复制带噪模拟波形。这使数字信息更适合远距离传输、存储和复制。但若噪声大到跨过判决边界，或者量化过粗造成信息丢失，数字系统同样会出错。

### 组合逻辑与时序逻辑是两类基本处理结构

若输出只依赖当前输入，可写成 $Y=F(X)$，这类系统属于组合逻辑。例如译码器、比较器和加法器只需根据当前码字给出结果。若输出还依赖先前状态，则需要状态变量 $Q$，系统关系变为：

$$
Q^{+}=H(X,Q), \qquad Y=G(X,Q)
$$

其中 $Q^{+}$ 表示下一状态。计数器、序列检测器和通信控制器都属于时序逻辑。区分二者时，不要只看电路中是否有“时钟”字样，而要问：输入撤掉以后，系统是否仍要记住某件事。

### 软件实现与专用硬件实现是两种权衡

同一逻辑任务可以由微处理器执行程序，也可以由专用数字电路并行完成。程序实现修改方便、复用性高，适合控制流程复杂而速度要求适中的任务；专用硬件能够并行运算、延迟确定，适合吞吐量或实时性要求高的任务，但修改代价通常更大。

可编程逻辑器件位于二者之间。CPLD、FPGA 内部含可编程逻辑块、存储资源和互连网络，设计者通过 HDL 描述功能，再由工具映射到器件。它仍是硬件并行执行，不等同于处理器逐条运行程序。选择实现路线时，应同时看功能规模、速度、功耗、开发周期、后续修改和批量成本。

### 从晶体管到系统必须分层

复杂数字系统不可能始终停留在晶体管连接层思考。教材展示了从元件级、门级、小规模和中规模集成电路，到大规模、超大规模集成电路，再到片上系统的层次。分层的价值是给每一层建立稳定接口：使用者先关心模块“做什么”，需要验证电气或时序问题时再进入“怎样做”。

门数只能粗略反映规模，真正选型还要检查 I/O 数、存储容量、时钟资源、乘法器等专用资源和布线限制。功能在逻辑上可描述，不等于目标器件一定容得下；资源超限或时序不满足时，必须重新划分模块、降低并行度或更换器件。

### 数字系统设计是规格驱动的闭环

设计应先把自然语言需求变成可验证规格：有哪些输入输出、编码含义是什么、允许多大延迟、是否需要保存状态、复位后进入什么状态、功耗和成本上限是多少。随后才选择结构与器件，完成逻辑设计、仿真、实现和测试。

规格 → 结构分解 → 逻辑设计 → 仿真与实现 → 板级验证 → 发现偏差后返回规格或结构，这是一条反复迭代的链。工具可以自动完成化简、综合和布局布线，但不能替设计者决定需求是否完整、接口语义是否一致，也不能替代对异常状态和边界条件的判断。

### 成本约束与功能约束必须同时满足

工程设计很少存在脱离代价的“绝对最佳”。选择更大的器件可以保留余量，却增加成本和功耗；压缩资源可以降低单价，却可能使时序紧张、调试困难。早期样机常优先选择可修改性，批量产品则更重视单位成本和稳定供应。做论述题时，应把选择理由落到具体约束，而不是笼统说某种技术“先进”。

## 解题流程

遇到系统框图或方案选择题，先按以下顺序判断：

1. 标出物理输入、物理输出和数字系统的边界。
2. 判断哪些接口需要 ADC、DAC、传感器、驱动或电平调整。
3. 检查输出是否只依赖当前输入；若不是，明确要保存的状态。
4. 根据速度、并行度、修改频率与成本选择处理器、专用逻辑或 FPGA。
5. 写出可验证指标，并说明设计验证失败后应回到哪一层修改。

若题目给出量化位数，第一步先写可用码字数 $2^n$，再结合满量程判断分档。若题目要求比较模拟与数字系统，先从信息表示和恢复方式解释，再谈抗干扰、存储、处理和失真边界。

## 易错点

- 把“脉冲”直接等同于“数字信号”。脉冲是模拟电压波形，只有赋予二值判决规则后才承载数字信息。
- 认为数字化没有误差。采样和量化都可能丢失信息，位数增加只能减小量化误差。
- 把 FPGA 当成运行 HDL 程序的普通处理器。综合后的逻辑在硬件中并行工作。
- 只按门数选器件，忽略 I/O、存储、时钟、布线、功耗和时序资源。
- 看到有输出就判断为组合逻辑，却没有检查输出是否依赖过去状态。
- 把仿真通过当成系统完成。电气接口、时钟、复位、外部噪声和执行机构仍需板级验证。
