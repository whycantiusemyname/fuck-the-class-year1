# 数字逻辑设计及应用 · S8 知识入口

这里是“数字逻辑与嵌入式系统”课程中《数字逻辑设计及应用》教材的 source-bound S8 记忆层。当前材料覆盖数字逻辑、存储器、可编程逻辑与现代数字系统设计，不把教材没有讲授的单片机指令、外设驱动、RTOS 或嵌入式软件开发自行补进来；若这些内容属于课程范围，需要以后用对应教材或课件另行入库。

当前无试卷统计，考试范围待确认。因此，本层只依据两册原始 PDF 建立教材主干与 S10 入口，不声称任何章节是高频考点。

## 三类文件怎么用

- 第一次系统学习某章：读 `主干讲解`。它负责建立连续的知识链、概念条件、典型推理与解题流程。
- 需要查来源、边界或题目触发信号：读 `grounding`。它负责把讲解重新钉回教材范围，并提示 S10 首轮追问。
- 已读过一遍、准备进入 S10 问答或做题：读 `S10 启动卡`。它只承担五分钟唤醒和路由，不替代主干讲解。

## 进入 S10 前

先选定章节并读主干讲解；能用自己的话复述该章知识链后，再读启动卡做最小自测。若答不上来，不要从启动卡硬背答案，而应按卡片路由回主干讲解对应小节。任何“必考、高频、近年趋势”判断都要等试卷入库并完成统计后再说。
