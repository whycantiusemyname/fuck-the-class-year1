**程序1** 设 $\Psi(x)=\sum_{k=1}^{\infty}\frac{1}{k(k+x)}$ ，分别取 x=0.0,0.5,1.0, $\sqrt{2}$ ,10.0,100.0,300.0,计算 $\Psi(x)$ 的近似值,要求截断误差在 $10^{-6}$ 内.

提示: 依据截断误差要求, 估计出 $k$ .

输出: $x$ 和 $\Psi(x)$ 的值.

> [!note]- 解答｜状态：独立解答未对照
>
> 对 $x\ge0$，正项单调下降。取 $N=10^6$，积分比较给出
> $$0<R_N\le\int_N^\infty\frac{dt}{t(t+x)}=\begin{cases}1/N,&x=0,\\\log(1+x/N)/x,&x>0.\end{cases}$$
> 后一上界不超过 $1/N=10^{-6}$。以下输出截断和及尾界；截断和本身是下界，加上尾界才是包含真值的区间。为严格小于阈值可改取 $N=1000001$。程序采用分块求和避免创建过大数组。
>
> ```python
> def psi(x, N=1000001):
>     total = 0.0
>     for a in range(1, N+1, 100000):
>         k = np.arange(a, min(a+100000, N+1), dtype=float)
>         total += np.sum(1/(k*(k+x)))
>     bound = 1/N if x == 0 else math.log1p(x/N)/x
>     return total, bound
> for x in [0, .5, 1, math.sqrt(2), 10, 100, 300]:
>     print(x, psi(x))
> ```
>
> 本次验收输出（人口单位千人；时间单位秒，随设备与计时分辨率变化）：
>
> ```text
> 0 (np.float64(1.6449330668497268), 9.99999000001e-07)
> 0.5 (np.float64(1.2274102777619682), 9.999987500015834e-07)
> 1 (np.float64(0.9999990000019998), 9.999985000023334e-07)
> 1.4142135623730951 (np.float64(0.8749819960231575), 9.999982928962997e-07)
> 10 (np.float64(0.29289582540332526), 9.999940000443329e-07)
> 100 (np.float64(0.05187277522789271), 9.999490034340732e-07)

**程序2** 下面给出美国 1920\~1970 年的人口表 (表 A1):

表 A1

| 年份 | 1920 | 1930 | 1940 | 1950 | 1960 | 1970 |
|---|---:|---:|---:|---:|---:|---:|
| 人口/千人 | 105711 | 123203 | 131669 | 150697 | 179323 | 203212 |

用表 A1 中数据构造一个 5 次 Lagrange 插值多项式, 并用此估计 1910 年, 1965 年和 2002 年的人口. 1910 年的实际人口数约为 91772000, 请判断插值计算得到的 1965 年和 2002 年的人口数据准确性是多少?

> [!note]- 解答｜状态：独立解答未对照
>
> 以 $t=(\mathrm{year}-1920)/10$ 缩放节点，计算五次 Lagrange 多项式。人口单位为千人；1910年真值应换为 $91772$ 千人。1965年位于节点内，2002年属于远距离外推。题目没有1965、2002年的真值，也没有人口函数的六阶导数界，故不能从表内数据给出这两年的准确位数或误差百分比。1910年的误差只检验该次外推，不能当作其他年份的误差保证。
>
> ```python
> years = np.array([1920,1930,1940,1950,1960,1970.])
> population = np.array([105711,123203,131669,150697,179323,203212.])
> nodes = (years-1920)/10
> def lagrange(x, y, t):
>     x, y = np.asarray(x, float), np.asarray(y, float)
>     if len(np.unique(x)) != len(x): raise ValueError("重复节点")
>     ans = 0.0
>     for i in range(len(x)):
>         q = 1.0
>         for j in range(len(x)):
>             if j != i: q *= (t-x[j])/(x[i]-x[j])
>         ans += y[i]*q
>     return ans
> for yr in [1910,1965,2002]:
>     print(yr, lagrange(nodes,population,(yr-1920)/10))
> p1910 = lagrange(nodes,population,-1)
> print("1910相对误差", abs(p1910-91772)/91772)
> ```
>
> 本次验收输出（人口单位千人；时间单位秒，随设备与计时分辨率变化）：
>
> ```text
> 1910 31872.0
> 1965 193081.51171875
> 2002 26138.748415991664
> 1910相对误差 0.6527045286143922
> ```
>
> 起手：先统一人口单位，并将年份平移缩放成等距小节点。

**程序4** 数据同表 A1, 用自然样条函数预测在 1910 年, 1965 年和 2002 年的人口数. 请比较以上三种方法所求值的效果, 哪一种方法最优?

> [!note]- 解答｜状态：独立解答未对照
>
> 数据表A1见程序2。自然样条要求端点二阶导数为零。用节点一阶导数 $m_i$ 作未知量，内部连续条件为
> $$h_i m_{i-1}+2(h_{i-1}+h_i)m_i+h_{i-1}m_{i+1}=3(h_i\delta_{i-1}+h_{i-1}\delta_i),$$
> 其中 $h_i=t_{i+1}-t_i$、$\delta_i=(y_{i+1}-y_i)/h_i$。自然边界为 $2m_0+m_1=3\delta_0$、$m_{n-1}+2m_n=3\delta_{n-1}$。下列实现将区间外点按首末段三次多项式延伸，这是额外公开的外推约定；自然样条本身仅由节点区间内条件确定。1965年可正常插值。1910、2002年不能仅凭自然边界获得可靠预测。Lagrange与Newton理论等价，缺少1965、2002真值时不能断言三者哪一个最优。
>
> ```python
> def spline_slopes(x,y,ends=None):
>     x,y = np.asarray(x,float),np.asarray(y,float)
>     h=np.diff(x); d=np.diff(y)/h; n=len(x)
>     if n < 2 or np.any(h<=0): raise ValueError("节点应严格递增")
>     A=np.zeros((n,n)); b=np.zeros(n)
>     for i in range(1,n-1):
>         A[i,i-1:i+2]=[h[i],2*(h[i-1]+h[i]),h[i-1]]
>         b[i]=3*(h[i]*d[i-1]+h[i-1]*d[i])
>     if ends is None:
>         A[0,0:2]=[2,1]; A[-1,-2:]=[1,2]
>         b[0]=3*d[0]; b[-1]=3*d[-1]
>     else:
>         A[0,0]=A[-1,-1]=1; b[0],b[-1]=ends
>     return np.linalg.solve(A,b)
> def spline_value(x,y,m,t):
>     i=int(np.clip(np.searchsorted(x,t)-1,0,len(x)-2))
>     h=x[i+1]-x[i]; u=(t-x[i])/h
>     return ((2*u**3-3*u**2+1)*y[i]+(-2*u**3+3*u**2)*y[i+1]
>             +(u**3-2*u**2+u)*h*m[i]+(u**3-u**2)*h*m[i+1])
> m=spline_slopes(nodes,population)
> for yr in [1910,1965,2002]:
>     print(yr,spline_value(nodes,population,m,(yr-1920)/10))
> ```
>
> 本次验收输出（人口单位千人；时间单位秒，随设备与计时分辨率变化）：
>
> ```text
> 1910 88219.0
> 1965 191909.78708133972
> 2002 330299.8517894738
> ```
>
> 起手：先写自然边界条件，再解节点导数的三对角线性系统。

**程序6** 用 Newton 插值计算 Hermite 插值.

输入：插值点数 n，插值点 $\{x_{i}, f(x_{i}), f'(x_{i})\}, i = 0, 1, 2, \cdots, n;$ 要计算的函数点 x.

输出: $H(x)$ 的值.

> [!note]- 解答｜状态：独立解答未对照
>
> 将每个节点重复两次，重节点的一阶差商取给定导数；其余差商按Newton递推。所得多项式次数不超过 $2n+1$，同时满足函数值与一阶导数条件。代码对导数条件用生成多项式的解析导数另行核验，不能只验函数值。
>
> ```python
> def hermite(x,y,dy,t):
>     x,y,dy=map(lambda a:np.asarray(a,float),(x,y,dy))
>     if len(np.unique(x))!=len(x): raise ValueError("原节点重复")
>     z=np.repeat(x,2); q=np.zeros((len(z),len(z)))
>     q[:,0]=np.repeat(y,2)
>     for i in range(1,len(z)):
>         q[i,1]=dy[i//2] if i%2 else (q[i,0]-q[i-1,0])/(z[i]-z[i-1])
>         for j in range(2,i+1): q[i,j]=(q[i,j-1]-q[i-1,j-1])/(z[i]-z[i-j])
>     c=np.diag(q); ans=c[-1]
>     for i in range(len(z)-2,-1,-1): ans=c[i]+(t-z[i])*ans
>     return ans
> print(hermite([0,1],[0,1],[0,3],.5))  # 应为x^3在0.5处的值0.125
> ```
>
> 本次验收输出（人口单位千人；时间单位秒，随设备与计时分辨率变化）：
>
> ```text
> 0.125
> ```
>
> 起手：把每个节点列两次，并用已知导数填重节点差商。

**程序8** 用复化 Simpson 自动控制误差方式计算积分 $S(x)=\int_{a}^{b}f(x)\mathrm{d}x$ .

输入: 积分区间 $[a, b]$ , 精度控制值 $e$ , 定义函数 $f(x)$ .

输出: 积分值 $S$ .

> [!note]- 解答｜状态：独立解答未对照
>
> 从偶数分段数 $n=2$ 起复化Simpson，反复加倍。对足够光滑且进入四阶渐近区间的函数，用 $|S_{2n}-S_n|/15$ 估计细网格误差；这属于事后估计，不是任意非光滑函数的严格误差界。程序返回细网格值、估计量与段数；未达精度时明确报错。
>
> ```python
> def simpson(f,a,b,tol=1e-8,max_n=1048576):
>     def value(n):
>         h=(b-a)/n
>         return h/3*(f(a)+f(b)+4*sum(f(a+i*h) for i in range(1,n,2))
>                     +2*sum(f(a+i*h) for i in range(2,n,2)))
>     n=2; old=value(n)
>     while n*2<=max_n:
>         n*=2; now=value(n); err=abs(now-old)/15
>         if err<=tol:return now,err,n
>         old=now
>     raise RuntimeError("未达估计精度")
> print(simpson(math.sin,0.,math.pi))
> ```
>
> 本次验收输出（人口单位千人；时间单位秒，随设备与计时分辨率变化）：
>
> ```text
> (2.000000004032257, 4.033182972780954e-09, 128)
> ```
>
> 起手：先取偶数分段，再按相邻两次Simpson值的差除以15控制加倍。

**程序9（选做）** 计算积分:

(1) $S = \int_{-\infty}^{\infty}\frac{1}{\sqrt{2\pi}}\mathrm{e}^{-x^2 /2}\mathrm{d}x;$ (2) $S = \int_0^\infty \frac{x\mathrm{d}x}{\mathrm{e}^x + 1}.$

算法: 计算以 $(a_{i}, b_{i})$ 为积分区间的积分序列 $c_{i} = \int_{a_{i}}^{b_{i}} f(x) \mathrm{d} x$ , 直到 $|c_{i} - c_{i-1}|$ 小于给定精度时停止. 例如, $(a_{i}, b_{i})$ 积分区间序列取

$(-1, 1), (-2, 2), (-3, 3), (-3.5, 3.5), (-3.7, 3.7), (-3.9, 3.9), \cdots$

输入：积分区间序列 $(a_{i},b_{i}),i=1,2,\cdots,m$ ，精度控制值e，定义函数 $f(x)$ .

输出: 积分值 $S$ .

> [!note]- 解答｜状态：独立解答未对照
>
> 原书按扩区间后两次积分差停止；这不能保证余下无穷尾部小于容差（区间扩得极小也会造成小差值）。实现仍输出原差值，但另加尾界验收。对(1)截在 $[-B,B]$，尾界为 $2e^{-B^2/2}/(B\sqrt{2\pi})$；对(2)截在 $[0,B]$，由 $1/(e^x+1)\le e^{-x}$ 得尾界 $(B+1)e^{-B}$。总误差预算分给有限区间Simpson估计和尾部。有限区间误差仍受程序8光滑/渐近假设约束。题中示例区间序列适用于(1)，(2)只扩右端。
>
