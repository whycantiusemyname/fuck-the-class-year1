## 使用顺序

完全没学过一章时先读主干讲解，建立方法为何出现、怎样计算、误差或收敛条件怎样约束结果的整体模型；随后用 grounding 核对教材公式、适用条件和带星边界；准备做题时再读 S10 启动卡，以最小自测暴露卡点并进入问答或演算。

## 范围审计

- 教材理论范围：绪论及第1—8章已覆盖；不带星的小节属于教材主干，但在缺少教学大纲或教师范围时，不直接等同于“考试必学”。
- 教材选用内容：第1章 Hermite 插值；第5章经典迭代法统一形式；第6章重积分与 Gauss 型求积；第7章 Euler 收敛性证明与绝对稳定性；第8章实对称 Jacobi 与 QR。教材星号提供“选用”证据，但是否讲授、是否考试仍待确认。
- 教材附录：作为辅助来源，不替代正式章节三件套。
- 教师重点、停讲内容与试卷考频：尚无证据，不作推断。
