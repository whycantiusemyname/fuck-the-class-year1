设线性表存放在向量 $A[1\ldots\mathrm{MAXNUM}]$ 的前 $\mathrm{elenum}$ 个分量中，且递增有序。试写一算法，将 $x$ 插入线性表的适当位置，以保持线性表的有序性。

> [!note]- 解答｜状态：独立解答未对照
> **思路：** 有序表从尾部向右移动，避免尚未处理的元素被覆盖。用下列 Python 写法表达算法；`A[0]` 不使用，实际容量为 `len(A)-1`，`n` 对应题中的 $\mathrm{elenum}$。
>
> ```python
> def insert_sorted(A, n, x):
>     if not 0 <= n < len(A):
>         raise ValueError("表长不合法")
>     if n == len(A) - 1:
>         raise OverflowError("顺序表已满")
>     i = n
>     while i >= 1 and A[i] > x:
>         A[i + 1] = A[i]
>         i -= 1
>     A[i + 1] = x
>     return n + 1
> ```
>
> 循环后 $A[1..i]\le x$，后移部分均大于 $x$，故插入后仍有序；重复关键字插在已有相等项之后。最坏时间 $O(n)$，额外空间 $O(1)$。
>
> **核验：** 已枚举长度0—4、取值为 $\{-1,0,1\}$ 的全部非降表及插入值，与排序结果比对；空表、首尾插入、重复值和满表均已检查。
>
> 起手：先检查容量，再从表尾向右移动所有大于 $x$ 的元素。

设有多项式

$$
A(x)=1+5x+7x^3-9x^7+5x^{16},
$$

$$
B(x)=4x+7x^4+4x^7-3x^{15}+x^{16}.
$$

1. 用单链表给出 $A(x)$ 和 $B(x)$ 的存储表示；
2. 以上述两个单链表为基础，通过插入和删除等运算给出 $A(x)+B(x)$ 的存储表示。

> [!note]- 解答｜状态：独立解答未对照
> 每个结点存放 $(\text{系数},\text{指数},\text{next})$，头结点不计入有效项，按指数递增连接：
>
> $$
> \begin{aligned}
> A:&\quad h_A\to(1,0)\to(5,1)\to(7,3)\to(-9,7)\to(5,16)\to\varnothing,\\
> B:&\quad h_B\to(4,1)\to(7,4)\to(4,7)\to(-3,15)\to(1,16)\to\varnothing.
> \end{aligned}
> $$
>
> **相加操作：** 顺序扫描两链。指数较小的项先保留；指数相同则系数相加，和为0时删除该项；一条链结束后接入另一条链的余项。例如 $x^1$ 项合为9，$x^7$ 项合为 $-5$，$x^{16}$ 项合为6，$x^4,x^{15}$ 项依次插入。
>
> $$
> h\to(1,0)\to(9,1)\to(7,3)\to(7,4)\to(-5,7)\to(-3,15)\to(6,16)\to\varnothing.
> $$
>
> **结果：**
> $$
> A(x)+B(x)=1+9x+7x^3+7x^4-5x^7-3x^{15}+6x^{16}.
> $$
> 若原地修改 $A$，将 $B$ 中缺少指数的结点插入相应位置，相同指数就修改 $A$ 的系数并释放多余结点。扫描复杂度 $O(m+n)$，无须按指数逐个空查。
>
> **核验：** 在 $x=-2,-1,0,1,2$ 处复算两边均相等；指数0—16逐项系数也一致。本题没有系数相加后为0的项。
>
> 起手：先约定结点中系数和指数的次序，再按指数归并两条链。

设两个栈共占一维数组空间 $S[m]$，它们的栈底分别设在一维数组的两端，且进栈的每个数据元素只占一个分量。试编写这两个栈公用的栈操作算法，取栈顶元素 $\operatorname{get}(i)$，其中 $i$ 为 0 或 1，用以指示堆栈号。

> [!note]- 解答｜状态：独立解答未对照
> 采用零起始数组 `S[0..m-1]`，$m\ge1$。栈0从左向右长，栈1从右向左长，初始化 `top=[-1,m]`。
>
> ```python
> def push(S, top, i, x):
>     if i not in (0, 1):
>         raise ValueError("非法栈号")
>     if top[0] + 1 == top[1]:
>         raise OverflowError("共享数组已满")
>     top[i] += 1 if i == 0 else -1
>     S[top[i]] = x
>
> def get(S, top, i):
>     if i not in (0, 1):
>         raise ValueError("非法栈号")
>     if (i == 0 and top[0] == -1) or (i == 1 and top[1] == len(S)):
>         raise IndexError("空栈")
>     return S[top[i]]
>
> def pop(S, top, i):
>     x = get(S, top, i)
>     top[i] += -1 if i == 0 else 1
>     return x
> ```
>
> `get(i)` 只读栈顶，不删除；`pop(i)` 才移动栈顶。满条件为 $\mathrm{top}[0]+1=\mathrm{top}[1]$，空条件分别为 $-1,m$。每次操作时间、额外空间均为 $O(1)$。
>
> **核验：** 已对容量1—4穷举深度6内的两栈入栈/出栈序列，与两个普通栈逐步比对；检查了共享满、空栈、非法栈号及 `get` 不改变状态。
>
> 起手：先让两个栈顶从数组两端相向增长，再分别判空并统一判满。

试找出分别满足下列条件的所有二叉树：

1. 先序遍历序列和中序遍历序列相同；
2. 中序遍历序列和后序遍历序列相同；
3. 先序遍历序列和后序遍历序列相同。

> [!note]- 解答｜状态：独立解答未对照
> 按遍历的是各个不同结点的身份（结点不混同）解释：
>
> 1. **先序等于中序：** 先序首项是根；中序中根之前是左子树，故左子树必须空。对右子树递归同理，所有结点均无左孩子，即右单链。
> 2. **中序等于后序：** 后序末项是根；中序中根之后是右子树，故右子树必须空。递归得到左单链。
> 3. **先序等于后序：** 根同时在序列首、末，非空且结点互异时只能有一个结点。因此只有单结点树，若允许空树则空树也满足。
>
> 空树、单结点树也属于前两类的退化情况。若只比较可重复的数据值而不区分结点，结论不再成立，例如各结点值都相同；这不是本题通常的结点序列口径。
>
> **核验：** 已枚举0—5个结点的全部有序二叉树形态，逐一比较遍历，恰得到上述三类。
>
> 起手：比较根在两种遍历中的位置，再把相同条件递归应用到剩余子树。
