## 5 分钟地图

网络与分层 → TCP/IP → 地址、端口与服务 → Socket 编程 → Web → 网络安全 → 物联网与移动互联网。

## 题型分流

- 分层与协议：先定位功能所在层。
- IP 与子网：先由掩码拆网络位和主机位。
- TCP/UDP 与 Socket：先判断服务性质和通信端点角色。
- Web 与安全：先分协议、内容表示、威胁目标和保护措施。

## 第一动作

先判断题目所在协议层和通信端点，再明确需要可靠性、实时性、寻址、进程区分还是安全保护。

## 最小自测

1. TCP 与 UDP 的核心差别是什么？
   - 答案要点：TCP 面向连接、可靠、字节流；UDP 无连接、开销小、不保证可靠。
2. TCP 服务端的基本 Socket 调用顺序是什么？
   - 答案要点：`socket-bind-listen-accept-read/write-close`。
3. HTTP 与 HTML 为什么不是同类概念？
   - 答案要点：HTTP 是应用层通信协议，HTML 是网页内容的标记语言。
4. 子网题怎样得到网络地址？
   - 答案要点：将 IP 地址与子网掩码逐位相与。
