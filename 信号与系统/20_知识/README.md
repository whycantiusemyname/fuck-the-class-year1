# 《信号与系统（第二版）》S8 知识入口

这里是《信号与系统（第二版）》的 source-bound S8 记忆层。内容严格依照两册扫描教材的 11 个正式章节生成；附录、文献目录和基本题答案没有被虚构为独立章节，也没有引入教材外的现代通信、控制或数字信号处理理论。

`课程口径.md` 尚未确认教学和考试范围，当前无试卷统计。因此，下列章节只是全书学习主线，不代表“全部必考”，也没有任何高频排序。

## 三层材料怎么用

- 第一次学习：读 `主干讲解`，先建立章节问题、整体直觉、公式条件和解题过程。
- 查来源与边界：读 `grounding`，确认教材页段、课程用语、题目信号和不能越过的范围。
- 已学过并准备进入 S10：读 `S10 启动卡`，用五分钟地图和最小自测唤醒；它不替代主干讲解。

## 进入 S10 前

选定章节后先读主干讲解，并尝试复述“本章的新问题—核心工具—成立条件—典型第一步”。答不上来就按启动卡路由回主干对应小节，不要只背卡片结论。任何“必考、高频、近年趋势”判断都要等试卷入库并完成 S2 统计后再添加。
