# 微积分 II 课件梳理索引

## 使用口径

- 课程口径: 当前课程未单独设置 `课程口径.md`，按兼容规则以本目录收录的 40 份课件 PDF 为知识边界。
- 学习目标: 面向大学课程的快速理解与应试复习；优先降低理解阻力，必要时保留充分解释，不以机械压缩篇幅为目标。
- 范围约束: 题库与考频只用于判断复习优先级和选择真题入口，不能单独授权加入课件之外的理论、记号或证明工具。
- 顺序: 按用户指定，以课件日期为正确顺序。
- 主线: 40 个课件 PDF 全量纳入；标题含“习题课”“复习”的文件作为复习节点保留在时间线中。
- 页码: 页码按 PDF 页计；本轮先做章节主干梳理和检索入口，不粘贴课件长段原文。
- 考频对接: 考频快照按23份卷、378个唯一题目锚点统计；后续解答索引另计24份文件、420个解答块，去重后403个不同题号，两者不是同一统计口径。见 [[微积分/40_派生视图/解答完成索引|解答完成索引]]。章节笔记末尾保留真题锚点与考频入口。
- 总览入口: [[微积分/20_知识/整体知识框架#总主线|整体知识框架]] 已按当前四份章节笔记和知识点级考频结果刷新。

## 主线与补充层级

- 表中标为 `主线` 的课件按日期推进新概念；`Mar27th.pdf` 是第五章条件极值到第六章重积分的交界节点。
- `Apr3rd.pdf`、`Apr22ndII.pdf`、`Apr24th.pdf`、`May22nd.pdf`、`Jun5th.pdf` 只作对应章节的习题或复习补充，不另起知识主线。
- 四份章节笔记按“主线概念先读、复习节点回查”的层级组织；完整 40 份课件映射只保留在本 README。
- 章节笔记中的术语和结论以对应来源课件为准；材料未讲明的扩展不写入应试主线，无法从材料裁决的内容应列为范围待确认。
