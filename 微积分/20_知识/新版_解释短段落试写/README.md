> 本文件夹是按新版 S8 可读性规则写出的知识主干副本。外层正式文档未改动。

## 使用方式

- 先读 [[微积分/20_知识/新版_解释短段落试写/整体知识框架_可读版#总主线|整体知识框架]]，知道四章各在解决什么问题。
- 再按当前复习目标进入章节文件。
- 每章优先看 `这一章抓什么`、`分节主干` 里的 `解释` / `怎么用` 块，最后用 `解题流程` 检查能不能动手。

## 本版写法

- 新概念第一次出现时，用 `解释` 先说明它解决什么问题。
- 重要公式后面写“怎么用”，包括题目信号、第一步、符号对应和常见坑。
- 正文按电子阅读拆短段，不把多个任务塞进一个长段落。
- LaTeX 公式尽量带解释性标注，例如 `\underbrace{...}_{\text{...}}`、`\boxed{...}`、`\color{...}`。
