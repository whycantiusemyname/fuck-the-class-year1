## 教学主线与概念依赖

先区分可移动的电子、空穴与固定杂质离子，再解释浓度差导致的扩散、空间电荷与内建电场，最后说明外加偏置如何改变净电流。由真实曲线过渡到三种大信号近似和工作点处的小信号切线，应用电路都回到“假设状态—列方程—验证条件”。

先修是电压参考方向、KCL/KVL、直流与交流分量，以及电容的直流稳态/交流阻抗性质。数学桥是局部一阶线性化与周期平均；不要求在本章另教课件外的半导体输运方程、量子隧穿计算或完整通信调制理论。

## 课程记号、公式与成立条件

| 对象 | 核心关系与含义 | 必须保留的条件 |
| --- | --- | --- |
| 本征浓度 | $n_i=p_i=BT^{3/2}e^{-E_G/(2kT)}$；$T$为绝对温度，$E_G$为禁带宽度 | 热平衡本征材料；不可抽出幂次作为任意器件电导率定律 |
| 端电压与电流 | $u_D=V_A-V_K$；正电流由A流向K | 看相对电位，不看单端对地正负 |
| PN结电流 | $i_D=I_S(e^{u_D/U_T}-1)$，$U_T=kT/q$ | 本章理想关系，不描述反向击穿；室温热电压约26mV，不是0.7V压降 |
| 小信号电阻 | $r_d=U_T/(I_{DQ}+I_S)\approx U_T/I_{DQ}$ | 先求正向Q点，近似要求 $I_{DQ}\gg I_S$；仅描述足够小的增量 |
| 稳压分流 | $I_Z=(U_i-U_Z)/R-U_Z/R_L$ | 先假设稳压，再验电流窗口及 $U_ZI_Z$ 功耗；不满足即重算工作区 |
| 无滤波整流 | 半波 $U_O\approx0.45U_2$；桥式 $U_O\approx0.9U_2$ | 正弦输入、$U_2$为有效值、理想管、电阻负载；不是滤波后输出或输出有效值 |
| 并联钳位 | 上限 $E+U_D$，下限 $E-U_D$ | 分别对应阳极接输出/阴极接输出；必须先确认电池和二极管方向 |
| 包络检波 | $T_c\ll RC\ll T_m$ | 放电时间常数的尺度判断；充电路径不同，不能一概套同一个R |

$R_D=U_D/I_D$ 是直流割线比，$r_d$ 是正向工作点的切线电阻，$r_z=\Delta U_Z/\Delta I_Z$ 是稳压区动态电阻，三者不可互换。总瞬时量、直流分量、交流增量、有效值与振幅应在建模前标清。

第45页并联下限幅的原文字与图示连接矛盾。图中阳极接基准 $E$，阴极接输出，因此导通时 $E-u_O=U_D$；4V基准与0.7V压降给出3.3V下限，不是4.7V。转换稿保留原文并附局部勘误，主干采用与电路/KVL一致的推导。第44—47页涉及串并联与方向时，均从端电压重新判断，不能把某页的压降数字当通用口诀。

## 题目入口、最小动作与误概念

| 学生卡点 | 首个动作 | 错因识别 |
| --- | --- | --- |
| N型“带负电”、耗尽层“没电荷” | 分别画可移动载流子与固定离子 | 把导电载流子类型混成净电荷 |
| 多管导通判断 | 标A/K，提出状态组合，重新算公共节点 | 把初始开路电压当最终电压 |
| 小信号不会建模 | 先求Q点，再画交流增量图 | 未偏置就使用 $r_d$，或把0.7V留在交流图 |
| 稳压范围 | 写电阻电流等于负载与稳压管电流之和 | 忘记窗口/功耗，或只检查名义负载 |
| 整流与限幅 | 写出当前区间等效电路 | 把桥式单管平均一半错用于瞬时电流；钳位压降符号错误 |
| 检波 | 画导通充电和截止放电两个阶段 | 只用线性模型解释频率变换；只追求大RC忽略包络跟踪 |

## S10 主动诊断与变式种子

先问学生：N型半导体为什么可以电中性？若答成“因为电子不带电”，退回5.1—5.3；若能区分固定离子，再问反偏为什么仍有小电流。不要在这一关直接要求记住全部器件参数。

给同一管两个不同偏置电流，让学生比较 $r_d$，再让其说明为什么不能用于截止区。进入电路题后只改变一个条件：从理想管到恒压降，再从直流到小增量；观察是否主动补上Q点与模型适用条件。

给稳压电路先减小负载电阻，再提高输入电压，要求先预测电流方向变化、再计算极端窗口。给并联限幅只反转二极管或基准电源，让学生必须通过A/K方程求边界。给包络检波分别增大、减小RC，要求区分纹波与对角线失真。
