# 电路分析与模拟电路知识区

这里存放经过课件对照后形成的章节主干笔记。`00_原材料/` 保留原始课件，`20_知识/` 用于第一次建立整体理解和冲刺阶段查阅。

## 范围口径

- 当前课程尚未设置 `课程口径.md`，因此本知识区严格以本页“章节与课件映射”列出的课件为内容边界。
- 第 6 章的层级由用户明确指定：6-5 只补充 6-4 的输出级与带负载问题，6-7 只补充 6-6 的带宽与稳定性问题，二者不单列为主要内容。
- 已有[考频矩阵](../40_派生视图/考频矩阵.md)与[主题题表](../40_派生视图/主题题表.md)，范围为成惠历年期末卷第5—9章（13卷114题）；课后习题、仿真与复习资料不计入该真题频率。各章“复习优先级”仍表示课件理解顺序，不能直接当作统计排序。
- 课件外理论、无法追溯的术语和未解决的课件冲突不写入正文；如后续出现，统一列入对应章节的“范围待确认”。

## 建议阅读顺序

1. [[电路分析/20_知识/整体知识框架|先看第5至9章整体知识框架]]，确认每章在完整系统中的位置。
2. 零基础或刚开始本章时，先读对应的“入门讲解”，形成术语、第一步和小自测闭环。
3. 需要系统复习或考前查漏时，再读对应的“主干重点”。
4. S10 私教会话恢复上下文时，优先读取对应的 `grounding`。

## 第6章主干顺序

第6章内容最多，按下面顺序读：

1. 6-1：器件工作区和控制关系。
2. 6-2：偏置、静态工作点、小信号模型与基本接法。
3. 6-3：把同一套分析框架迁移到 MOS/FET。
4. 6-4：多级级联、差分输入与实际放大器结构。
5. 6-5：只作为多级放大器输出级和带负载能力的补充。
6. 6-6：用负反馈换取稳定性、阻抗和失真改善。
7. 6-7：只作为负反馈之后理解通频带与稳定性的补充。

## 使用约定

- 各章第一次学先读“入门讲解”；已有基本概念后，再读“主干重点”中的“先建立整体直觉”和“本章怎么串起来”，最后进入分节主干。
- `grounding` 主要给 S10 会话恢复和教学约束使用，不替代学生端入门讲解。
- 章节笔记中的课件文件名用于追溯来源；只有定位具体图形或推导时才需要页码。
- 题目、锚点和题型标签属于 `10_题库/`；完整解答由 S9 写入题库，不放进本知识区。
