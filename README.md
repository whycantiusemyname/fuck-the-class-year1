## 完整使用

```sh
git lfs install
git clone https://github.com/whycantiusemyname/fuck-the-class-year1.git
cd fuck-the-class-year1
git lfs pull
```

超过普通 Git 单文件限制的各科原始 PDF 使用 Git LFS。下载 ZIP 可能只得到 LFS 指针，完整使用请按上面的命令克隆。

使用 Obsidian 将**整个仓库根目录**打开为一个库，保留课程文件夹名称和相对位置。原有双链、题号锚点、折叠题解、公式和图片按 Obsidian 格式保存；GitHub 网页可阅读标准 Markdown，部分 Obsidian 特有语法需要本地打开。需要 AI 私教时，安装主项目技能，并显式要求在本仓库运行 Fuck The Class。

## 资源清理与边界

本仓库是原工作区的独立分享副本。保留课件、题面、题解、讲解、索引，以及文档实际引用的资源；`90_缓存` 中被引用的文件继续保留，不能整目录删除。没有复制个人学习事件、做题记录、收件箱截图、学生状态快照和无引用的运行环境、压缩包、转换中间件。

[导出清单](export-manifest.json)记录发布文件大小与 SHA-256。导出审计留在发布工作区；核验、审计、对比渲染产物与课程处理脚本不发布。同名 PNG/PDF 已有 SVG 时只发布 SVG，并修正阅读文档中的引用。

发布筛选规则在 [publish_policy.py](tools/publish_policy.py)。[旧导出脚本](tools/export_year1.py)仍固定处理原有三科，不能用它重新生成本轮九科完整清单；本轮按各科已校验的精确清单增量同步。物理分享版标签计数按实际发布子集生成，不直接沿用本地全册计数。
