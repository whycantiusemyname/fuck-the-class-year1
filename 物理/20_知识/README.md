# 物理 S8 知识库索引

本目录是 `$fuck-the-class` S8 章节材料层。已按当前要求重做为**单章粒度**：任何一个 S8 文件只覆盖一个教材章节，不再使用 `第01-03章`、`第13-20章` 这类合并章文件。

三类文档按角色分目录保存：

- `主干讲解/`：给学生建立第一轮 mental model。
- `grounding/`：给 AI tutor 控制来源、边界、题型信号和 probe。
- `S10启动卡/`：给学生进入 S10 问答、做题、纠错前快速启动。

## 教材来源

- `扫描件_普通高等教育十三五规划教材.pdf`: 上册教材，第1-9章。
- `大学物理学（下册）（第二版） (孙云卿，雷雨) (z-library.sk, 1lib.sk, z-lib.sk).pdf`: 下册教材，第10-20章。
- `扫描件_普通高等教育十一五规划教材配套教辅.pdf`: 已作为 S1 学习指导题库入库；本轮不再把它混入教材 S8 主干讲解。

## 使用方式

- 初学或重新建模：先读 `主干讲解/` 下对应章节。
- 让 AI tutor 严格贴合课程范围：使用 `grounding/` 下对应章节。
- 准备进入 S10 问答、做题、纠错：先读 `S10启动卡/` 下对应章节。

## 范围说明

- 本轮只按教材章节拆分和重做 S8；不新增课外理论。
- 学习指导题库的格式问题走 S1 检查与报告，不混入 S8 主干讲解。
- 若后续拿到教师课堂删减/补充，需要更新本 README 与对应 chapter grounding 的“范围待确认”。
