## 课程用语与记号

- 章节名：热力学。
- 受控题型：`学习指导｜热力学综合`。
- 本知识库默认符号：$A$ 表示系统对外做功，$Q$ 表示系统吸收热量，第一定律写作 $Q=\Delta E+A$。
- 常用符号：$E$ 内能，$C_V$ 定体摩尔热容，$C_p$ 定压摩尔热容，$\gamma=C_p/C_V$，$\eta$ 热机效率，$\omega$ 制冷系数，$S$ 熵。
- 注意：若题目使用外界对系统做功的符号，必须先转换符号，不直接套本文件口径。

## 公式 / 方法 / 条件

- 理想气体状态方程：$pV=\nu RT$。
- 内能变化：$\Delta E=\nu C_V\Delta T$；理想气体内能只由温度决定。
- 第一定律：$Q=\Delta E+A$，其中 $A=\int p\,\mathrm{d}V$ 为系统对外做功。
- 等体：$A=0$，$Q=\Delta E$。
- 等压：$A=p\Delta V=\nu R\Delta T$，$Q=\nu C_p\Delta T$。
- 等温理想气体：$\Delta E=0$，$Q=A=\nu RT\ln(V_2/V_1)$。
- 绝热：$Q=0$，$A=-\Delta E$；准静态绝热可用 $pV^\gamma=\text{常量}$、$TV^{\gamma-1}=\text{常量}$。
- 循环：$\Delta E_{\text{cycle}}=0$，$Q_{\text{net}}=A_{\text{net}}$；效率 $\eta=A_{\text{net}}/Q_{\text{in}}$。
- 卡诺热机：$\eta=1-T_2/T_1$。
- 卡诺制冷机：$\omega=Q_2/A=T_2/(T_1-T_2)$。
- 可逆过程熵变：$\Delta S=\int \delta Q_{\mathrm{rev}}/T$；理想气体熵变可用 $\nu C_V\ln(T_2/T_1)+\nu R\ln(V_2/V_1)$，只在课程题面需要时调用。

## 题型信号与第一步

| 题型信号 | 第一动作 |
| --- | --- |
| p-V 图、直线/折线过程 | 标方向，算面积 $A$，由初末态算 $\Delta E$ |
| 等体、等压、等温、绝热 | 写该过程关键条件，不混公式 |
| 判断吸热/放热 | 用 $Q=\Delta E+A$ 判断正负 |
| 循环过程 | 整体 $\Delta E=0$，逐段找吸热段和净功 |
| 卡诺热机/制冷机 | 温度换 K，确认热源温度和 $Q_1,Q_2,A$ 方向 |
| 可逆/不可逆、熵 | 先判是否可逆，再决定是否用 $\Delta S=\int \delta Q_{\mathrm{rev}}/T$ |
