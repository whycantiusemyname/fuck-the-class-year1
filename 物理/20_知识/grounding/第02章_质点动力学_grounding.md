## 本章主线

从第01章的运动描述进入动力学解释：选研究对象，画外力，写约束，用

$$
\sum\vec F=m\vec a
$$

建立瞬时方程；再按题目需要转成冲量-动量、功-动能或机械能形式。S10 中不要直接给最终公式，优先 probe 学生是否会选对象和画受力图。

## 课程用语与记号

| 术语/记号 | 本章含义 | S10 提醒 |
| --- | --- | --- |
| 研究对象 | 单物体或系统 | 要求内力时必须拆对象 |
| 受力图 | 外界对对象的力 | 不画对象对外界的力 |
| $\sum\vec F=m\vec a$ | 牛顿第二定律 | 矢量式，按方向列方程 |
| $N,T,f$ | 支持力、张力、摩擦力 | 条件不同，不能互相替代 |
| $f_s\le\mu_sN$ | 静摩擦上限 | 静摩擦不默认取最大 |
| $f_k=\mu_kN$ | 滑动摩擦 | 方向反相对运动 |
| $\vec I=\int\vec F\,\mathrm dt$ | 冲量 | 适合短时间、平均力 |
| $W=\int\vec F\cdot\mathrm d\vec r$ | 功 | 适合位移和速率变化 |
| $U=-GMm/r$ | 万有引力势能 | 大尺度引力不用 $mgh$ |

## 公式 / 方法 / 条件

| 公式/方法 | 使用条件 | 第一检查 |
| --- | --- | --- |
| $\sum\vec F=m\vec a$ | 惯性系、质点模型 | 对象和坐标轴是否明确 |
| $a=v\,\mathrm dv/\mathrm dx$ | 已知 $F(x)$ 或 $a(x)$ | 一维或沿路径使用 |
| $\vec I=\Delta\vec p$ | 力随时间、碰撞、平均力 | 动量是矢量 |
| $W_{\text{合}}=\Delta K$ | 位移-速度关系 | 合外力总功 |
| $W_{\text{非保守}}=\Delta E_{\text{机械}}$ | 摩擦、阻力等非保守力 | 不要误判机械能守恒 |
| $F_n=mv^2/R=m\omega^2R$ | 圆周运动法向 | 指出提供向心力的实际力 |
| $f_s\le\mu_sN$ | 不滑动条件 | 先求所需静摩擦 |
| $N\ge0$ | 接触保持条件 | $N<0$ 表示脱离 |
| $U=-GMm/r$ | 万有引力势能 | 零势能取无穷远 |

## S10 主动 probe 种子

1. 这题你选哪个对象？如果改选整体，哪些力会变成内力？
2. 你画的每一个力是谁施加给谁的？
3. 静摩擦是已知最大值，还是需要先由方程求出来？
4. 绳长不变给了哪个加速度关系？
5. 圆周运动中，法向合力由哪些实际力提供？
6. 这题适合瞬时受力、冲量，还是功-能？为什么？
7. 如果结果里 $N<0$ 或 $f_s>\mu_sN$，物理上说明什么？
