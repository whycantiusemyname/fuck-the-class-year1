## 本章主线

周期性晶体结构使外层价电子在周期性原子实势场中公有化；单个原子能级在 $N$ 个原子组成晶体后分裂为 $N$ 个密集新能级，形成能带。电子按能量最低原理和泡利不相容原理填充能带，满带、未满带、空带和禁带的关系决定导体、绝缘体、半导体的导电性。半导体部分继续区分本征半导体、杂质半导体、n 型/p 型、施主/受主能级，并用 pn 结说明二极管单向导电。

S10 对话中优先让学生先画最小能带图，再说“有没有未满带/禁带多宽/有没有杂质能级”，不要直接给完整答案。

## 课程用语与记号

- 晶体：长程有序、几何对称排列、空间点阵、元胞。
- 周期势场：原子实周期性排列形成的势场；价电子还受平均场近似作用。
- 公有化电子：外层电子不再属于某个单独原子，而在晶体中共有化运动。
- 能带：单原子能级在晶体中分裂形成的密集能级范围。
- 禁带：能带之间电子不允许取值的能量间隔；能带重叠时禁带消失。
- 价带：由价电子能级分裂成的能带。
- 满带：被电子填满的能带；普通条件下不导电。
- 空带：未被电子填充的能带；被激发进入电子后可成为导带。
- 导带：能够导电的能带；未满带是导带，空带被激发后也可导电。
- 载流子：参与导电的电子或空穴。
- 本征半导体：较纯净、无杂质和缺陷的半导体；载流子为电子和空穴。
- 杂质半导体：掺入少量其他元素后形成，分 n 型和 p 型。
- 施主能级：五价杂质引入，禁带中靠近导带/空带，容易供给电子。
- 受主能级：三价杂质引入，禁带中靠近满带/价带，容易接受电子。
- 费米面/费米能级：教材在 pn 结能量解释中用作“电子填充到的最高能级”。

## 公式 / 方法 / 条件

| 公式 / 方法 / 判据 | 条件与含义 | S10 提醒 |
| --- | --- | --- |
| $N$ 个原子形成晶体时，单原子某一能级分裂成 $N$ 个接近新能级 | 由公有化电子和周期势场引起；$N$ 很大时形成近似连续能带 | 追问“为什么不是一个能级仍保持不变？” |
| 副量子数 $l$ 的次壳层形成 $(2l+1)$ 个支能带，最多容纳 $2(2l+1)N$ 个电子 | 教材用 $s,p,d,f$ 表说明；计入自旋 | 只要求理解填充容量，不扩展到高级能带计算 |
| 满带普通条件下不导电 | 所有能级被占据，泡利不相容原理限制电子进入邻近状态，净效应不能形成电流 | 让学生说“没有可进入的空状态” |
| 未满带能导电 | 有电子且有未占据的稍高能级，外电场可推动电子转移 | 导体判据核心 |
| 导体判据：存在未满带，或满带与空带重叠形成未满带 | 教材 18.3.2 导体部分 | 能带图题先找未满带 |
| 绝缘体判据：只有满带和空带，不重叠，禁带较宽 | 普通外电场下电子不能跨越禁带；强场可击穿 | 比较题要写“禁带宽” |
| 半导体判据：结构类似绝缘体，但禁带较窄 | 光照、温度等外界影响可使电子跃迁到空带 | 强调“敏感性”，不是只背“介于中间” |
| 本征半导体导电 | 满带电子被激发到空带，产生导带电子和价带空穴 | 载流子必须写电子和空穴 |
| 五价杂质 → n 型半导体 | 施主能级在禁带中靠近导带；多数载流子为电子 | 题面“五价、磷、砷、锑”先走 n 型入口 |
| 三价杂质 → p 型半导体 | 受主能级在禁带中靠近价带/满带；多数载流子为空穴 | 题面“三价、硼、镓、铟”先走 p 型入口 |
| $\lambda_{\max}=hc/E_g$ | 光子能量 $E=hc/\lambda$ 至少等于禁带宽度；常见于最大吸收波长题 | 可用 $\lambda(\mathrm{nm})\approx1240/E_g(\mathrm{eV})$，注意单位 |
| pn 结单向导电 | 正向电压降低势垒，反向电压提高势垒；反向电流很小 | 只按教材层次讲，不扩展半导体器件方程 |

## 题型信号与第一步

| 题型信号 | 第一动作 | 期望学生说出的核心 |
| --- | --- | --- |
| “满带、空带、导带” | 先按填充状态定义，再说能否导电 | 满带填满不导电；空带被激发后可导；导带能导电 |
| “导体/绝缘体/半导体” | 画能带示意，找未满带或禁带宽度 | 导体有未满带；绝缘体禁带宽；半导体禁带窄 |
| “禁带宽度、最大波长、吸收辐射、光电导” | 写 $hc/\lambda_{\max}=E_g$ 并统一单位 | $E_g$ 越大，最大波长越短 |
| “四价半导体掺五价元素” | 写多余电子和施主能级 | n 型，多数载流子电子，施主靠近导带 |
| “四价半导体掺三价元素” | 写缺电子/空穴和受主能级 | p 型，多数载流子空穴，受主靠近价带 |
| “施主/受主能级位置” | 先判断它供电子还是收电子 | 施主靠近导带；受主靠近满带/价带 |
| “pn 结、二极管、单向导电” | 先说扩散、内建电场、势垒 | 正向降势垒，反向升势垒 |

## S10 主动 probe 种子

1. 这张能带图里有没有未满带？如果没有，满带和空带是否重叠？
2. 你说它是半导体，依据是“禁带窄”还是只是背了材料名？
3. 五价杂质为什么叫施主？它把电子送到哪里去？
4. 三价杂质为什么对应空穴？受主能级靠近哪一边？
5. 本征半导体里电子和空穴为什么成对出现？
6. 禁带宽度变大时，最大可吸收波长应该变大还是变小？用 $E=hc/\lambda$ 解释。
7. 满带不导电的关键是“没有电子”还是“没有可进入的空状态”？
8. pn 结正向电压到底改变了什么：载流子种类、禁带宽度，还是势垒？
