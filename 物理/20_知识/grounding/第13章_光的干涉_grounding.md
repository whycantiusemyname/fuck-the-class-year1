## 本章主线

本章主线是“相干光叠加 -> 光程差 -> 明暗条件 -> 条纹位置/移动”。S10 中优先要求学生说清：

1. 两束相干光分别是哪两束；
2. 光程差来自几何路程、介质附加、膜厚、镜面移动还是气体折射率变化；
3. 反射题中是否存在相对半波损失；
4. 题目问的是条纹位置、条纹间距、膜厚、折射率、曲率半径还是条纹移动数。

## 课程用语与记号

- 光程：$L=\sum n_i s_i$。
- 光程差：$\Delta=L_2-L_1$，符号按选定两束光顺序。
- 相位差：$\Delta\varphi=2\pi\Delta/\lambda$；若有相对半波损失，另加 $\pi$ 或等效 $\lambda/2$。
- 双缝参数：缝距 $d$ 或 $a$，屏距 $D$，条纹位置 $x$，级次 $k$。
- 薄膜参数：折射率 $n_1,n_2,n_3$，膜厚 $e$，折射角 $r$。
- 劈尖参数：劈尖角 $\theta$，条纹间距 $b$，局部厚度 $e\approx\theta x$。
- 牛顿环参数：环半径 $r_k$，曲率半径 $R$，膜折射率 $n$。
- 迈克耳孙参数：反射镜移动 $d$，条纹移动数 $N$，插入薄片厚度 $e$。

## 公式 / 方法 / 条件

| 公式或方法 | 使用条件 | tutor probe |
| --- | --- | --- |
| $\Delta\varphi=2\pi\Delta/\lambda$ | 两束相干光到同一点；$\lambda$ 按题目给定介质/空气约定 | “你写的 $\Delta$ 包含哪几段光程？” |
| 明暗条件 $\Delta=k\lambda$、$\Delta=(k+\frac12)\lambda$ | 无相对半波损失时的常用形式；有半波损失时需对调 | “反射处折射率是从小到大还是从大到小？” |
| 双缝 $\Delta\approx d x/D$, $x_k=kD\lambda/d$ | 远屏、小角、近轴 | “题目问单侧位置还是两侧距离？” |
| 插薄片附加光程 $(n-1)e$ | 一路垂直穿过薄片、其余为空气近似 | “附加光程加在哪一路？中央明纹向哪边移动？” |
| 薄膜 $\Delta_{\text{film}}=2ne\cos r$ | 上下表面反射光，需另判半波损失 | “上下两束反射光相对多了几个半波损失？” |
| 劈尖 $e\approx\theta x$, $b=\lambda/(2n\theta)$ | 小角、相邻同类条纹、等厚干涉 | “条纹移动表示固定点厚度改变了多少？” |
| 牛顿环 $e\approx r^2/(2R)$, 常见暗环 $r_k^2=kR\lambda/n$ | 反射光、接触中心、薄层折射率 $n$；中心条件改变时需重判 | “题目给直径、弦长还是半径？” |
| 迈克耳孙 $2d=N\lambda$ | 单臂反射镜移动 $d$，往返光程改变 | “这是镜子移动还是薄片插入？有没有往返因子 2？” |

## 题型信号与第一步

- `干涉｜光程差`：题面出现介质板、光程、相位差、薄片插入。第一步写每一路光程。
- `干涉｜双缝干涉`：题面出现杨氏双缝、缝距、屏距、中央明纹、白光重叠。第一步写 $\Delta\approx dx/D$。
- `干涉｜薄膜干涉`：题面出现增透膜、肥皂膜、油膜、反射增强/相消。第一步判 $n_1,n_2,n_3$ 的半波损失。
- `干涉｜劈尖干涉`：题面出现空气劈尖、金属丝、工件缺陷、条纹间距或条纹移动。第一步写 $e=\theta x$。
- `干涉｜牛顿环与迈克耳孙`：题面出现牛顿环半径/直径/曲率半径、反射镜移动、条纹移动数、气体折射率测量。第一步写膜厚函数或光程改变 $N\lambda$。

## S10 主动 probe 种子

1. 这道题的两束相干光分别是哪两束？

7. 迈克耳孙题里光程改变有没有往返因子 2？
