## 本章主线

用大量分子的统计平均解释宏观热学量：理想气体模型给出压强公式，温度联系平均平动动能，麦克斯韦速率分布描述速率区间占比，能均分给出内能，玻尔兹曼分布处理有势能差时的数密度变化。

## 课程用语与记号

- 章节名：统计物理初步。
- 受控题型：`学习指导｜统计物理综合`。
- 常用符号：$N$ 分子数，$n=N/V$ 分子数密度，$m$ 单个分子质量，$\mu$ 摩尔质量，$k$ 玻尔兹曼常量，$R$ 气体常量，$i$ 自由度，$f(v)$ 速率分布函数。
- 注意：$\bar v$ 是平均速率，$v_{\mathrm{rms}}$ 是方均根速率，$\overline{v_x}$ 是速度分量平均；不要混用。

## 公式 / 方法 / 条件

- 理想气体状态方程：$pV=NkT=\nu RT$。
- 压强公式：$p=\frac13nm\overline{v^2}$，基于平衡态、各向同性、理想气体分子模型。
- 温度公式：$\frac12m\overline{v^2}=\frac32kT$，只对应平均平动动能。
- 麦克斯韦速率分布：
  - $\mathrm{d}N/N=f(v)\,\mathrm{d}v$。
  - 区间占比为 $\int_{v_1}^{v_2}f(v)\,\mathrm{d}v$，区间分子数为 $N\int_{v_1}^{v_2}f(v)\,\mathrm{d}v$。
  - 区间平均速率为 $\dfrac{\int_{v_1}^{v_2}vf(v)\,\mathrm{d}v}{\int_{v_1}^{v_2}f(v)\,\mathrm{d}v}$。
- 常见速率：$v_p=\sqrt{2kT/m}$，$\bar v=\sqrt{8kT/(\pi m)}$，$v_{\mathrm{rms}}=\sqrt{3kT/m}$。
- 能均分：每个二次型自由度平均能量 $\frac12kT$；理想气体内能 $E=\frac{i}{2}\nu RT=\frac{i}{2}\frac{M}{\mu}RT$。
- 混合气体：分压相加；内能按各成分物质的量和自由度相加。
- 玻尔兹曼分布：$n=n_0e^{-E_p/kT}$；等温大气 $p=p_0e^{-\mu gh/(RT)}$。

## 题型信号与第一步

| 题型信号 | 第一动作 |
| --- | --- |
| 标准状况、分子数、数密度 | 用 $pV=NkT$，先统一单位 |
| 平均平动动能、温度 | 用 $\frac32kT$，确认不是总内能 |
| 自由度、单原子/双原子、内能 | 判定 $i$，写 $E=\frac{i}{2}\nu RT$ |
| 速率分布曲线、斜线面积 | 说明面积是占比，乘 $N$ 才是分子数 |
| 区间平均速率 | 写带归一化分母的积分 |
| 混合气体 | 分压相加，内能按成分相加 |
| 大气压、高度、玻尔兹曼 | 检查等温假设，代 $E_p=mgh$ |
