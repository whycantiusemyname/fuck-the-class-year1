## 本章主线

先不研究受力原因，只建立运动描述语言：$\vec r(t)$、$\vec v(t)$、$\vec a(t)$、轨迹、平均量、切向/法向分解、角量关系、相对速度。S10 中优先让学生说清“函数入口、曲线入口、参考系入口”是哪一个，再给公式。

## 课程用语与记号

| 术语/记号 | 本章含义 | S10 提醒 |
| --- | --- | --- |
| $\vec r(t)$ | 位置矢量/运动方程 | 末端轨迹不等于完整运动信息 |
| $\Delta\vec r$ | 位移 | 矢量，区别于路程 |
| $\bar{\vec v}$ | 平均速度 | 位移除以时间 |
| $\bar v$ | 平均速率 | 路程除以时间 |
| $\vec v$ | 速度矢量 | $|\mathrm d\vec r/\mathrm dt|$ 才是速率 |
| $\vec a$ | 加速度矢量 | 不一定沿速度方向 |
| $a_t$ | 切向加速度 | 改变速率 |
| $a_n$ | 法向加速度 | 改变方向 |
| $\omega,\alpha$ | 角速度、角加速度 | 圆周运动转线量时使用 |
| $\vec v_{A/B}$ | A 相对 B 的速度 | 下标必须先定义 |

## 公式 / 方法 / 条件

| 公式/方法 | 使用条件 | 第一检查 |
| --- | --- | --- |
| $\vec v=\mathrm d\vec r/\mathrm dt$ | 已知位置随时间 | 先分量求导 |
| $\vec a=\mathrm d\vec v/\mathrm dt=\mathrm d^2\vec r/\mathrm dt^2$ | 已知速度或位置 | 区分矢量和大小 |
| 轨迹方程 | 已知参数式 $x(t),y(t)$ | 消去 $t$，但别丢运动方向 |
| $a_t=\mathrm dv/\mathrm dt$ | 曲线运动速率变化 | $v$ 是速率 |
| $a_n=v^2/\rho$ | 曲线运动方向变化 | $\rho$ 是曲率半径，圆周时 $\rho=R$ |
| $v=R\omega$ | 圆周运动 | 半径是否恒定 |
| $a_t=R\alpha,\ a_n=R\omega^2$ | 圆周运动 | 变速圆周要两个分量 |
| $a=v\,\mathrm dv/\mathrm dx$ | 已知 $a(x)$ 或求 $v(x)$ | 一维沿轨迹使用 |
| $\vec v_{A/B}=\vec v_A-\vec v_B$ | 相对运动 | 明确参考系 |

## 题型信号与第一步

| 受控标签 | 题面信号 | 第一动作 |
| --- | --- | --- |
| `运动学｜向量运动方程` | 给 $\vec r(t)$、$x(t),y(t)$ | 分量求导，合成大小方向 |
| `运动学｜切向法向加速度` | 圆周、曲线、斜抛、曲率半径 | 先画速度方向，再分解加速度 |
| `运动学｜一维运动求导` | 给 $x(t)$ 或直线运动 | 求 $v(t),a(t)$，注意路程 |
| `运动学｜速度位置微分关系` | 给 $a(x)$、阻力与速度关系 | 用链式关系或分离变量 |
| `运动学｜相对运动` | 船、水、风、飞机、观察者 | 写 $\vec v_{A/G}=\vec v_{A/B}+\vec v_{B/G}$ |
| `运动学｜位置函数与轨迹` | 问轨迹、直线/曲线、平均量 | 区分参数方程和轨迹方程 |
| `学习指导｜运动学综合` | 多入口综合 | 先判入口，不直接套匀变速公式 |

## S10 主动 probe 种子

1. 题目给的是运动方程还是轨迹方程？
2. 你求的是速度矢量、速率、平均速度还是平均速率？
3. 这个加速度是在改变速率，还是改变速度方向？
4. 圆周运动里 $a_t$ 和 $a_n$ 分别是多少？
5. 已知 $a(x)$ 时，为什么不能只写 $a=\mathrm dv/\mathrm dt$？
6. 相对运动里，哪个速度是相对地面，哪个是相对水/风/观察者？
7. 你的答案方向如何表达？是否只给了大小？
