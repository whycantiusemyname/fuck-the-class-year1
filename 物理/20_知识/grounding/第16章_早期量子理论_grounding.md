## 本章主线

经典连续图像在微观辐射和原子现象中失效。本章按实验事实逐步引入量子思想：

> 黑体辐射 → 能量子 ε=hν
> 光电效应 → 光子能量/动量与光电方程
> 氢原子光谱 → 定态、角动量量子化、能级跃迁
> 康普顿效应 → 光子与电子碰撞，能量动量守恒
> 激光基础 → 受激辐射、粒子数反转、谐振腔

S10 讲解时优先让学生先判现象类型，再写公式；不要把 $hc/\lambda$、光电方程、康普顿公式和里德伯公式混成无差别公式库。

## 课程用语与记号

- $\nu$：频率；$\lambda$：波长；$\lambda_m$：黑体辐射能量密度峰值对应波长。
- $h$：普朗克常量；$\hbar=h/(2\pi)$。
- $\varepsilon=h\nu$：能量子或光子能量。
- $A$ 或 $W$：金属逸出功；$\nu_0$：红限频率；$U_a$：遏止电压。
- $p=h/\lambda$：光子动量。
- $m_0$：电子静质量；$\lambda_c=h/(m_0c)$：电子康普顿波长。
- $\phi$：康普顿散射角；$\theta$：反冲电子角度，若题面使用。
- $n,m$：氢原子量子数；谱线公式中通常 $n>m$，固定 $m$ 决定线系。
- $E_n=-13.6\,\mathrm{eV}/n^2$：氢原子能级。
- $R$：里德伯常量。
- 激光术语：自发辐射、受激辐射、受激吸收、粒子数反转、抽运/泵浦、光学谐振腔、工作物质。

## 公式 / 方法 / 条件

| 来源小节 | 公式/方法 | 使用条件 | Tutor 提醒 |
| --- | --- | --- | --- |
| 16.1 黑体辐射 | $T\lambda_m=b$，$b=2.897\times10^{-3}\,\mathrm{m\cdot K}$ | 黑体或近似黑体，峰值波长与温度互求 | 先统一 $\lambda_m$ 单位；不要把普通单色光题误判为黑体题 |
| 16.1 普朗克假说 | $\varepsilon=h\nu$ | 一定频率电磁辐射与物质交换能量 | 强调“能量交换一份一份”，不是普通代数换元 |
| 16.3 光子说 | $\varepsilon=h\nu=hc/\lambda$，$p=h/\lambda$，教材用 $m=\varepsilon/c^2$ | 光子能量、动量、光压、光子数题 | 同时说明光子静止质量为零，按教材题目口径处理质量量度 |
| 16.3 光电效应 | $h\nu=A+E_{k,\max}$ | 单个光子被金属电子吸收，电子逸出表面 | 先判 $h\nu\ge A$；光强只改饱和光电流，不改最大初动能 |
| 16.3 红限 | $h\nu_0=A$ | 求截止频率/红限波长或判断能否发生光电效应 | $\lambda_0=c/\nu_0=hc/A$，波长越短能量越高 |
| 16.3 遏止电压 | $E_{k,\max}=e|U_a|$，$h\nu=A+e|U_a|$ | 反向电压刚好使最快光电子不能到达阳极 | 注意取绝对值；遏止电压与频率线性相关 |
| 16.4 比热量子解释 | 经典高温 $C_V=3R$；量子模型取 $E=n\varepsilon$ | 用于解释低温比热偏离能均分定理 | 题库不一定高频，讲概念即可，不扩展到德拜模型 |
| 16.5 氢原子线系 | $1/\lambda=R(1/m^2-1/n^2)$，$n=m+1,\dots$ | 氢原子谱线、线系极限、可见区巴耳末线系 | 固定终态 $m$ 决定线系；发射时 $n>m$ |
| 16.5 玻尔量子化 | $mvr=n\hbar$ | 玻尔允许圆轨道 | 不让学生把玻尔轨道当现代精确图像；本章按模型计算 |
| 16.5 能级 | $r_n=(n^2/Z)a_0$，氢原子 $E_n=-13.6\,\mathrm{eV}/n^2$ | 氢原子/类氢离子半径、能级、电离能 | $E<0$ 表示束缚态；电离终态取 $0$ |
| 16.5 跃迁 | $h\nu=|E_i-E_f|$ | 原子吸收或发射光子 | 先判断发射/吸收方向，再取正的光子能量 |
| 16.7 康普顿效应 | $\Delta\lambda=\lambda-\lambda_0=2(h/m_0c)\sin^2(\phi/2)=\lambda_c(1-\cos\phi)$ | X 射线或高能光子与近似自由电子散射 | $\phi=0$ 不变，$\phi=\pi$ 最大；与散射物质无关 |
| 16.7 反冲电子能量 | $K_e=hc/\lambda_0-hc/\lambda$ | 题目要求反冲电子动能，忽略其他能量损失 | 先用康普顿公式得散射波长，再用光子能量差 |
| 16.8 激光基础 | $h\nu=E_2-E_1$；粒子数反转 + 受激辐射 + 谐振腔 | 概念题、结构题 | 三部分：工作物质、激励能源、光学谐振腔 |

## 题型信号与第一步

受控题型标签：`学习指导｜早期量子综合`。

| 题面信号 | 第一动作 | 主要风险 |
| --- | --- | --- |
| 峰值波长、天体表面温度、黑体 | 写 $T\lambda_m=b$ | nm、Å、m 单位混乱 |
| 波长/频率、求光子能量动量质量 | 写 $\varepsilon=hc/\lambda$、$p=h/\lambda$ | 忘记 $\lambda\nu=c$；把静止质量说错 |
| 金属、逸出功、红限、遏止电压 | 比较 $hc/\lambda$ 与 $A$ | 光强和频率角色混用 |
| 光电子进磁场做圆周运动 | 先由磁场半径求 $v$ 或动能，再回到光电方程 | 漏掉 $qvB=mv^2/R$ 与光电方程联立 |
| X 射线、散射角、反冲电子 | 写康普顿 $\Delta\lambda$，再算能量差 | 把散射当吸收逸出 |
| 氢原子、莱曼/巴耳末/帕邢、能级 $n$ | 画能级方向，定 $m,n$ | 发射/吸收方向和终态线系看错 |
| 电离能、最长波长、基态/激发态 | 终态取自由电子 $E=0$ 或识别初态能级 | 负能级差取号错误 |
| 自发/受激、粒子数反转、激光器 | 先说发光机制，再说结构 | 只背特点，不说必要条件 |

## S10 主动 probe 种子

1. 这题属于黑体、光电、康普顿、氢谱线还是激光机制？你用哪个关键词判断？
2. 如果是光电效应，单个光子的能量是多少？是否超过逸出功？
3. 光强变大时，你认为最大初动能变不变？为什么？
4. 康普顿散射角为 $0$ 和 $180^\circ$ 时，$\Delta\lambda$ 应该分别怎样？这能帮你检查公式吗？
5. 氢原子从 $n=4$ 跃迁到 $m=2$ 是哪个线系？发射还是吸收？
6. $E_n$ 是负数时，电离能应该怎么取？
7. 自发辐射和受激辐射发出的光，在哪些性质上不同？
8. 激光为什么需要粒子数反转？如果低能级粒子更多，会发生什么？
