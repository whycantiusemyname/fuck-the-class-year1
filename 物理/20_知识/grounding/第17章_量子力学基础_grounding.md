## 本章主线

古典量子论的人为量子条件不足 → 德布罗意物质波把粒子性与波动性联系起来 → 玻恩概率解释把波函数模平方解释为概率密度 → 不确定关系给出经典位置-动量图像的边界 → 薛定谔方程描述波函数演化 → 定态、本征值和标准条件给出量子化 → 无限深势阱、势垒贯穿、氢原子和多电子原子展示方法。

S10 tutor 应优先训练学生的“题面信号 → 第一动作”，不要直接塞完整解法。若学生只背公式，追问公式条件和物理图像。

## 课程用语与记号

- 物质波 / 德布罗意波：$\lambda=h/p$，$E=h\nu$。
- 概率波：$\Psi$ 或 $\psi$ 描写状态，$|\Psi|^2=\Psi^*\Psi$ 为概率密度。
- 标准化条件：波函数单值、连续、有限；归一化条件为全空间概率积分等于 1。
- 不确定关系：教材标准式 $\Delta q\,\Delta p_q\ge \hbar/2$；估算题可能按题面使用 $h$、$\hbar$ 或 $\hbar/2$。
- 定态：$\Psi(\mathbf r,t)=\psi(\mathbf r)e^{-iEt/\hbar}$，概率密度不随时间变。
- 一维无限深势阱：通常取 $0\le x\le a$，阱外 $\psi=0$，边界 $\psi(0)=\psi(a)=0$。
- 量子数：$n,l,m_l,m_s$，注意教材有时把磁量子数写作 $m$，学习指导常写 $m_l$。

## 公式 / 方法 / 条件

| 内容 | 公式 / 方法 | 使用条件 / tutor 提醒 |
| --- | --- | --- |
| 德布罗意关系 | $p=h/\lambda$，$E=h\nu$ | 先找动量；宏观物体也有波长但通常不可观测 |
| 非相对论加速电子 | $p=\sqrt{2meU}$，$\lambda=h/\sqrt{2meU}\approx 12.25/\sqrt{U}\,\text{\AA}$ | 初速为零、非相对论、$U$ 用伏特数值；高速题改相对论 |
| 相对论动量入口 | $pc=\sqrt{E_k^2+2E_km_0c^2}$，$\lambda=h/p$ | 题面出现“可与光速比拟”“考虑相对论效应” |
| 概率密度 | $\rho=|\Psi|^2$ | 复函数取模平方，不是直接平方 |
| 归一化 | $\int |\Psi|^2d\tau=1$；一维为 $\int|\psi|^2dx=1$ | 只在非零定义域积分；归一化后再求概率 |
| 区间概率 | $P=\int_{x_1}^{x_2}|\psi(x)|^2dx$ | 无限深势阱常考半区间、局部区间 |
| 不确定关系 | $\Delta q\Delta p_q\ge\hbar/2$ | $\Delta$ 是不确定范围，不是变化量；按题面口径调整常数 |
| 能量-时间不确定 | $\Delta E\Delta t\ge\hbar/2$ | 主要用于能级寿命和谱线宽度的定性/估算 |
| 含时薛定谔方程 | $i\hbar\partial\Psi/\partial t=-(\hbar^2/2m)\nabla^2\Psi+V\Psi$ | 教材将其作为基本方程，不要求从经典力学严格推出 |
| 定态方程 | $-(\hbar^2/2m)\nabla^2\psi+V\psi=E\psi$ | 势能不显含时间；本征值 $E$ 是可观测能量 |
| 无限深势阱能级 | $E_n=n^2\pi^2\hbar^2/(2ma^2)=n^2h^2/(8ma^2)$ | $0\le x\le a$，$n=1,2,\cdots$，有零点能 |
| 无限深势阱波函数 | $\psi_n=\sqrt{2/a}\sin(n\pi x/a)$ | 仅对 $0\le x\le a$ 的常用坐标成立；换坐标时按题给边界重写 |
| 方势垒贯穿 | $E<U$ 时仍有透射概率 | 势垒越高/越宽，透射越小；边界用波函数和一阶导数连续 |
| 氢原子量子数 | $n=1,2,\cdots$，$l=0,\cdots,n-1$，$m_l=0,\pm1,\cdots,\pm l$ | $n$ 主决定能级，$l$ 决定角动量大小，$m_l$ 决定角动量分量 |
| 角动量 | $L=\sqrt{l(l+1)}\hbar$，$L_z=m_l\hbar$ | 不要用玻尔 $L=n\hbar$ 替代本章量子力学结论 |
| 自旋 | $m_s=\pm1/2$ | 自旋类比“自转”只作形象说明，不作经典实在图像 |
| 泡利与容量 | 次壳层 $2(2l+1)$，主壳层 $2n^2$ | 同一原子内不能有两个电子四个量子数全同 |

## 题型信号与第一步

| 题面信号 | 第一动作 |
| --- | --- |
| 给速度、动能、加速电压、波长 | 先求动量 $p$，再用 $\lambda=h/p$ |
| 提到“可与光速比拟”“100 kV”“相对论效应” | 不直接用 $p=mv$，先用相对论能量-动量关系 |
| 圆孔/晶体/衍射斑角半径 | 先算物质波波长，再接波动光学公式 |
| 给 $\Delta x$、$\Delta p$、波长精度 | 先判断 $\Delta$ 的含义和题面常数口径，再用不确定关系 |
| 给分段 $\psi(x)$ 和常数 $A/C$ | 先归一化，后求 $|\psi|^2$ 和概率 |
| 一维无限深势阱、$0\sim a$、宽度 $d$ | 写 $E_n=n^2h^2/(8md^2)$ 或按边界重写波函数 |
| 询问“概率最大位置” | 对 $|\psi|^2$ 判断极值，不对 $\psi$ 本身判断 |
| 势垒、隧道、扫描隧道显微镜 | 比较 $E$ 与 $U$，说明非零透射及高度/宽度影响 |
| 四个量子数、壳层、分壳层、泡利 | 逐层列 $n,l,m_l,m_s$ 取值；容量用计数公式 |

## S10 主动 probe 种子

1. 这题给的是粒子性数据还是波动性数据？你准备怎样在 $p$ 和 $\lambda$ 之间转换？
2. 你的 $\Delta x$ 是位置不确定范围，还是粒子实际走过的距离？
3. 这个波函数在哪些区间非零？归一化积分上下限是什么？
4. 你求的是概率密度还是某区间概率？为什么需要积分？
5. 无限深势阱的边界条件是哪两个？为什么 $E=0$ 不允许？
6. 势垒题中 $E<U$ 时，经典结论和量子结论分别是什么？
7. 给定 $n=3$，$l$ 和 $m_l$ 的允许取值各是什么？
8. 两个电子的前三个量子数相同是否一定违反泡利原理？还要看什么？
