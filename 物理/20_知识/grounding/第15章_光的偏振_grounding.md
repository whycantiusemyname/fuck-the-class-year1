## 本章主线

本章主线是“横波振动方向 -> 偏振状态 -> 偏振片投影 -> 反射起偏 -> 双折射/波片相位差”。S10 中优先让学生先说入射光状态和器件顺序，再写光强或角度公式。

## 课程用语与记号

- 光强：$I$、$I_0$。
- 偏振片透振方向 / 偏振化方向：题目中常用 $P_1,P_2,P_3$ 表示。
- 夹角：$\alpha$，必须明确是入射线偏振方向与偏振片方向的夹角，还是相邻偏振片方向夹角。
- 马吕斯定律：$I=I_0\cos^2\alpha$，用于线偏振光通过偏振片。
- 自然光首片：理想情况下 $I=I_0/2$。
- 布儒斯特角 / 起偏角：$i_B$，$\tan i_B=n_2/n_1$，且 $i_B+r=90^\circ$。
- 双折射：$o$ 光、$e$ 光、光轴、主截面。
- 波片相位差：$\Delta\varphi=2\pi |n_o-n_e|d/\lambda$。

## 公式 / 方法 / 条件

| 公式或方法 | 使用条件 | tutor probe |
| --- | --- | --- |
| 自然光过首片 $I=I_0/2$ | 理想偏振片，不考虑吸收反射 | “这是自然光第一次过偏振片吗？” |
| 马吕斯定律 $I=I_0\cos^2\alpha$ | 入射到该片前已经是线偏振光 | “$\alpha$ 是哪两个方向之间的角？” |
| 三片偏振片 $I=(I_0/2)\prod\cos^2\Delta\alpha_i$ | 自然光依次通过多个理想偏振片 | “每过一片后偏振方向更新成哪一个？” |
| 混合光 $I=I_n/2+I_p\cos^2\alpha$ | 入射光为自然光和线偏振光叠加 | “最大值和最小值分别来自哪个角度？” |
| 布儒斯特 $\tan i_B=n_2/n_1$ | 自然光在界面反射光完全偏振 | “反射线和折射线是否垂直？折射光是否只是部分偏振？” |
| 临界角到布儒斯特角 | 已知介质对空气全反射临界角 | “先由临界角求折射率，再求空气入射的 $i_B$” |
| 波片相位差 | 双折射晶体，光轴方向已知，入射光可分解为两个主方向分量 | “入射振动方向与光轴夹角是多少？两个分量振幅是否相等？” |

## 题型信号与第一步

- `偏振｜马吕斯定律`：题面出现两个/三个偏振片、夹角、自然光、混合光、旋转偏振片最大最小。第一步写“入射状态 -> 第1片后状态 -> 第2片后状态”。
- `偏振｜布儒斯特角`：题面出现反射光完全偏振、起偏角、临界角、玻璃/水/空气界面。第一步画法线，写 $i_B+r=90^\circ$。
- `偏振｜双折射`：题面出现方解石、$o$ 光、$e$ 光、光轴、四分之一波片。第一步判断光轴和入射振动方向，分解互垂分量。
- `学习指导｜偏振综合`：可能混合多偏振片、混合光、波片和布儒斯特角；先判小题入口，不跨题型套公式。

## S10 主动 probe 种子

1. 入射光是自然光、线偏振光、混合光还是圆偏振光？
2. 第一片偏振片之后，光强和偏振方向分别变成什么？
3. 你用马吕斯定律时，$\alpha$ 是哪两个方向的夹角？
4. 三片偏振片题里，每一步的相邻夹角是多少？
5. 混合光题的最大值和最小值分别对应偏振片怎样放？
6. 反射光完全偏振时，折射光是否也完全偏振？为什么？
7. 波片题中两个互垂分量的振幅和相位差分别是多少？
