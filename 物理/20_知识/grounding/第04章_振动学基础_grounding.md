## 本章主线

稳定平衡附近的小偏离如果受到线性回复作用，就能写成

$$
\ddot{q}+\omega^2q=0.
$$

由此统一处理简谐振动方程、周期、相位、旋转矢量、能量、弹簧/单摆/等效系统和同频叠加。S10 中优先让学生先找平衡位置、选广义坐标、判断回复关系，再代入公式。

## 课程用语与记号

| 术语/记号 | 本章含义 | S10 提醒 |
| --- | --- | --- |
| 平衡位置 | 回复作用为零的参考位置 | 竖直弹簧先平移原点 |
| 简谐振动 | 满足 $\ddot{x}+\omega^2x=0$ 的振动 | 不是所有周期运动 |
| 振幅 $A$ | 最大位移大小 | 由初始条件决定 |
| 角频率 $\omega$ | 相位推进速率 | 多由系统参数决定 |
| 初相 $\varphi$ | $t=0$ 的相位 | 必须用速度符号判象限 |
| 相位 $\Phi$ | $\omega t+\varphi$ | 求最短时间用相位差 |

## 公式 / 方法 / 条件

| 公式/方法 | 使用条件 | 第一检查 |
| --- | --- | --- |
| $\ddot{x}+\omega^2x=0$ | 平衡附近线性回复 | 原点是否取在平衡位置 |
| $x=A\cos(\omega t+\varphi)$ | 余弦形式描述简谐振动 | $A,\omega,\varphi$ 是否分清 |
| $v=-A\omega\sin(\omega t+\varphi)$ | 由位移方程求导 | 速度符号决定相位分支 |
| $a=-\omega^2x$ | 简谐振动判据/结果 | 加速度指向平衡位置 |
| $\omega=\sqrt{k/m}$ | 理想弹簧振子 | 等效劲度系数和有效质量 |
| $T=2\pi\sqrt{m/k}$ | 理想弹簧振子 | 振幅不改周期 |
| $\omega=\sqrt{g/l}$ | 小角度单摆 | 需要 $\sin\theta\approx\theta$ |
| $A=\sqrt{x_0^2+(v_0/\omega)^2}$ | 已知初位移、初速度 | 初相仍需判象限 |
| $E=\frac12kA^2$ | 弹簧振子总能量 | 质量不直接进入总能量式 |
| $U=\frac12kx^2,\ K=\frac12k(A^2-x^2)$ | 弹簧振子能量分配 | 只能给大小，不能给方向 |
| 旋转矢量法 | 相位、最短时间、同频叠加 | 不要忽略 $v$ 的方向 |
| 串并联弹簧 | 线性弹簧等效 | 串联力同、并联位移同 |

| 受控标签 | 题面信号 | 第一动作 |

## S10 主动 probe 种子

1. 这题的平衡位置在哪里？你的 $x$ 是从哪里量起的？
2. 你能写出回复力或回复力矩与位移的关系吗？
3. $\omega$ 是系统给的，还是初始条件给的？
4. 只知道 $x_0$ 时，为什么还不能唯一确定初相？
5. 图上同一个位移为什么可能对应两个时刻？
6. 这题能用能量吗？如果能，能量能不能判断方向？
7. 弹簧串联/并联时，你用的是“力相同”还是“位移相同”？
8. 叠加题里两个振动是否同频？如果不同频，为什么不能写成单一简谐振动？
