# 第15章 光的偏振 S10启动卡

> 这是进入 S10 问答/做题前的启动卡，不替代 `主干讲解.md`。
> 完全没学过本章时，先读主干讲解；读过但准备做题时，再读这份。

## 5 分钟地图

本章做题先抓四个词：**入射状态、偏振方向、投影、起偏角**。

- 自然光第一次过理想偏振片：强度变为 $I_0/2$。
- 线偏振光过偏振片：用 $I=I_0\cos^2\alpha$。
- 多片偏振片：逐片更新偏振方向和光强。
- 反射光完全偏振：入射角是布儒斯特角，反射线垂直折射线。

## 题型分流

| 题面信号 | 第一动作 |
| --- | --- |
| 自然光过两个偏振片 | 先写第一片后 $I_0/2$，再乘 $\cos^2\alpha$ |
| 三个偏振片、两端正交 | 逐段写相邻夹角，中间片会让光重新透出 |
| 旋转偏振片有最大/最小 | 分开自然光恒定部分和线偏振可变部分 |
| 反射光完全偏振 | 写 $\tan i_B=n_2/n_1$，并用 $i_B+r=90^\circ$ |
| 临界角和起偏角同时出现 | 先由临界角求折射率，再求布儒斯特角 |
| 方解石、$o/e$ 光、波片 | 分解互垂分量，再看相位差 |

## 第一动作

读题后先写四行：

1. 入射光：自然光、线偏振光、混合光、圆偏振光？
2. 器件顺序：偏振片、界面、晶体、波片分别怎么排？
3. 角度：$\alpha$ 是相邻偏振片夹角，还是光矢量与偏振片夹角？
4. 目标：求光强、角度、折射率，还是偏振状态？

## 最小自测

1. 问：自然光通过第一个偏振片后强度是多少？  
   答案要点：理想情况下为 $I_0/2$，出射光变为线偏振光。
2. 问：两个正交偏振片中间插入第三个偏振片，为什么可能透光？  
   答案要点：中间片改变了进入最后一片的线偏振方向。
3. 问：混合光旋转偏振片时，最小光强为什么不一定为零？  
   答案要点：自然光部分通过偏振片后始终贡献 $I_n/2$。
4. 问：反射光完全偏振时，反射光和折射光有什么几何关系？  
   答案要点：二者互相垂直，$i_B+r=90^\circ$。
5. 问：四分之一波片要形成圆偏振，入射线偏振方向通常要怎样放？  
   答案要点：与晶片光轴成 $45^\circ$，让两个主方向分量振幅相等，并产生 $\pi/2$ 相位差。
