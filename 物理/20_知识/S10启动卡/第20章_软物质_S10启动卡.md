## 5 分钟地图

本章抓一句话：软物质在微弱外界作用下会发生显著宏观响应。教材主要讲四块：什么是软物质、液晶、聚合物体系、胶体。

| 入口 | 关键词 | 第一动作 |
| --- | --- | --- |
| 软物质定义 | 弱作用、强响应、自由能 | 说明 $F=E-TS$ 中熵项重要 |
| 液晶 | 流动性、取向有序、显示器 | 说清分子取向怎样影响光学性质 |

| 胶体 | 布朗运动、絮结、稳定剂 | 分析吸引和稳定机制的竞争 |

## 常用关系

- 自由能：$F=E-TS$。
- 软物质答题模板：对象结构 -> 外界作用 -> 响应机制 -> 宏观结果。
- 液晶：流动性 + 取向有序。
- 聚合物：长链构象熵决定弹性。
- 胶体：布朗运动、范德瓦尔斯吸引和稳定剂共同决定稳定性。

## 第一动作

读题后先写四行：

1. 对象：液晶、聚合物、胶体，还是软物质总定义？
2. 结构：取向分子、长链、交联网络、分散颗粒还是界面层？
3. 作用：温度、电场、拉伸、掺杂、溶剂碰撞还是浓度变化？
4. 结果：光学改变、弹性恢复、相变、稳定/絮结还是流变变化？

## 最小自测

1. 问：软物质为什么不能简单理解成“摸起来软”？  
   参考答案：教材强调的是微弱外界作用下形状或性质发生显著变化。

2. 问：液晶为什么既像液体又像晶体？  
   参考答案：它能流动，但分子取向有序并表现出光学各向异性。

3. 问：橡胶弹性的主要来源是什么？  
   参考答案：长链分子构象熵。拉伸使构象减少、熵降低，松手后系统趋向熵增。

4. 问：胶体为什么可能失稳？  
   参考答案：颗粒间有范德瓦尔斯吸引；若布朗运动或稳定剂不足，就会絮结沉淀。
