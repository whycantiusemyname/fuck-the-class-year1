## 5 分钟地图

本章做题先抓四个词：**事件、参考系、固有量、$\gamma$**。

- 事件：发光、接收、对齐、产生、衰变、碰撞前后。
- 参考系：谁静止，谁相对谁沿哪个方向运动。
- 固有量：同地的时间间隔是固有时间；物体静止系的长度是固有长度。
- $\gamma$：$\gamma=1/\sqrt{1-v^2/c^2}$，时间、长度、能量都绕它转。

## 题型分流

| 题面信号 | 第一动作 |
| --- | --- |
| 同时性、两个事件、两个惯性系 | 写出事件 1/2，标 $\Delta x,\Delta t$ 是哪个系测得 |
| 寿命、动钟、粒子飞行距离 | 找同地系，确定固有时间 $\Delta \tau$ |
| 尺、列车、飞船、立方体、刻痕 | 找固有长度，只收缩运动方向分量 |
| 两个速度、飞船抛物、B 看 C | 先定正方向，再用相对论速度合成 |
| 动能、总能量、质量增加 | 先求 $\gamma$，再分 $E_0,E,E_k,p$ |
| 碰撞合成、核反应、质量亏损 | 写能量/动量守恒或 $\Delta E=\Delta mc^2$ |

## 第一动作

读题后先写这四行：

1. 参考系：$S$ 与 $S'$ 分别是谁？相对速度方向是什么？
2. 事件：题中两个关键事件是什么？
3. 条件：哪个系同地？哪个系同时？哪个长度是固有长度？
4. 入口：洛伦兹变换、时间延缓、长度收缩、速度合成，还是能量关系？

## 最小自测

1. 问：两个事件在 $S$ 中不同地点同时发生，$S'$ 中一定同时吗？  
   答案要点：不一定，通常不同时；要看 $t'=\gamma(t-vx/c^2)$ 中的位置项。
2. 问：$\mu$ 子寿命题里，哪个时间是固有时间？  
   答案要点：$\mu$ 子自身参考系中产生和衰变同地，所以静止寿命是固有时间。
3. 问：一根斜杆沿 $x$ 方向运动，哪些量会变？  
   答案要点：平行于 $x$ 的长度分量收缩，垂直分量不收缩，因此总长度和角度都可能变。
4. 问：把 $m_0$ 粒子由静止加速到 $0.6c$，为什么不能用 $\frac12mv^2$？  
   答案要点：高速粒子用相对论动能 $E_k=(\gamma-1)m_0c^2$。
5. 问：两个粒子完全非弹性碰撞后合成一个粒子，合成静止质量为什么可能大于 $2m_0$？  
   答案要点：碰撞前的动能可转化为合成粒子的静止能量；相对论中守恒的是总能量和总动量。
