## 5 分钟地图

- 本章核心：从质点平动升级到刚体定轴转动。
- 起手顺序：对象和转轴 → 转动惯量 $J$ → 外力矩 → 选力矩方程/能量/角动量。
- 关键公式：$\sum M=J\beta$，$E_k=\frac12J\omega^2$，$L=J\omega$，$\boldsymbol{L}=\boldsymbol{r}\times m\boldsymbol{v}$。
- 高频入口：转动惯量与力矩、碰撞打杆、角动量守恒条件、转台飞轮系统。

## 题型分流

| 题面信号 | 第一动作 |
| --- | --- |
| 滑轮、飞轮、制动、张力 | 定轴和正方向，写 $\sum M=J\beta$ |
| 绳与轮无相对滑动 | 补 $a=R\beta$、$v=R\omega$ |
| 子弹打杆、嵌入、穿出 | 取固定轴，判断角动量守恒；别默认机械能守恒 |
| 人在转台上移动、飞轮啮合 | 系统外力矩小，比较前后总 $J\omega$ |
| 卫星远近点、中心力 | 关于中心看力矩，用 $\boldsymbol{r}\times m\boldsymbol{v}$ |

## 第一动作

读题后先写四行：

1. 对象：单个刚体，还是质点 + 刚体系统？
2. 转轴：固定轴、质心轴，还是某个参考点？
3. 入口：力矩方程、能量，还是角动量守恒？
4. 约束：有没有 $a=R\beta$、$v=R\omega$、共同角速度或无外力矩？

## 最小自测

1. 问：为什么刚体题要先选轴？  
   答案要点：力矩、角动量和转动惯量都依赖所选点或轴；轴不清，公式没有对象。
2. 问：合外力为零能直接推出角动量守恒吗？  
   答案要点：不能。角动量守恒要看关于所选点/轴的合外力矩是否为零。
3. 问：子弹嵌入细杆绕固定轴转动，为什么常用角动量守恒而不用机械能守恒？  
   答案要点：碰撞时间短，关于固定轴外冲量矩可忽略；完全非弹性碰撞有机械能损失。
4. 问：有质量滑轮两侧张力一定相等吗？  
   答案要点：不一定。若滑轮有角加速度，需要两侧张力差提供力矩。
