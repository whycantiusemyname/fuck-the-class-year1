# 第10章 静电学 S10启动卡

## 5 分钟地图

本章只抓一条链：

> 电荷 → 电场强度 E → 高斯定理/叠加积分 → 电势 U
> → 导体静电平衡 → 电介质极化与 D → 电容和电场能量

做题前先问：题目要的是场强、电势、通量、感应电荷、电容，还是能量？不要一上来套公式。

## 题型分流

| 题面信号 | 第一入口 |
| --- | --- |
| 点电荷、多个点电荷、电偶极子 | 画方向，用库仑定律或场强叠加 |
| 带电线、环、盘、球，且形状不够对称 | 取 $dq$，写 $d\boldsymbol E$ 或 $dU$，分量积分 |
| 球对称、柱对称、无限大平面 | 先试高斯面，看 $E$ 能否提出积分号 |
| 求电势、做功、动能变化 | 写电势差，确认零势点 |
| 导体、空腔、接地、金属板 | 先写导体内 $E=0$、导体等势、表面电荷条件 |
| 电介质、$\varepsilon_r$、束缚电荷 | 区分自由电荷和束缚电荷，再用 $\boldsymbol D$ 或 $\boldsymbol E$ |
| 电容器、串并联、插介质、拉板距 | 判断电源是否断开：固定 $Q$ 还是固定 $V$ |
| 电场能量、外力做功 | 看 $W_e$ 变化或用能量密度积分 |

## 第一动作

读题后先写四行：

1. 要求量：$\boldsymbol E$、$U$、$\Phi_e$、$q_{\text{感应}}$、$C$、$W_e$？
2. 对象与边界：真空/介质？导体/非导体？接地/不接地？电源断开/连接？
3. 入口：叠加积分、高斯定理、电势、电容关系，还是能量关系？
4. 检查：方向、正负号、单位、极限。

## 最小自测

1. 问：高斯面内没有净电荷，能否推出面上处处 $E=0$？  
   答案要点：不能。只能推出总电通量为零；面外电荷仍可使面上有场。

2. 问：什么时候高斯定理能直接求场强？  
   答案要点：电荷分布有足够对称性，能选高斯面使 $E$ 大小恒定且方向关系简单。

3. 问：电势为零的点，场强一定为零吗？  
   答案要点：不一定。场强由电势梯度决定，不由单点电势值决定。

4. 问：导体静电平衡最先写哪两个条件？  
   答案要点：导体内部 $E=0$；表面紧邻处场强垂直表面。由此导体是等势体。

5. 问：电容器插入电介质题，为什么要先看电源是否断开？  
   答案要点：断开时 $Q$ 固定；连接电源时 $V$ 固定。能量、电荷和场强变化会因此不同。
