# 第11章 静磁学 S10启动卡

## 5 分钟地图

本章只有一条主线：运动电荷和稳恒电流产生磁场，磁场再作用于运动电荷、电流和磁介质。

> 电流/运动电荷 → B 的计算 → B 的通量和环量 → 洛伦兹力/安培力 → 磁介质中的 H、M、B

抓四个入口：

- 求磁场：先看能否用安培环路定理；不能就拆电流元用毕奥-萨伐尔。
- 求粒子运动：画 $\mathbf v,\mathbf B,\mathbf f$，注意电荷正负。
- 求导线/线圈受力：写 $I\,\mathrm d\mathbf l\times\mathbf B$ 或 $\mathbf p_m\times\mathbf B$。
- 有磁介质：先问求 $\mathbf B$ 还是 $\mathbf H$，先用传导电流求 $\mathbf H$，再换算。

## 题型分流

| 题面信号 | 第一动作 |
| --- | --- |
| 载流直导线、圆环、半圆片、螺旋线 | 选电流元，判断各段 $\mathrm d\mathbf B$ 方向如何叠加 |
| 无限长、同轴、螺线环、无限大面电流 | 画安培环路，分段算包围电流 |
| 闭合曲面或半球面磁通量 | 补成闭合曲面，用总磁通量为零 |
| 带电粒子进磁场 | 画圆心、半径 $R=mv/(|q|B)$，负电荷方向反向 |
| 霍尔效应 | 判断载流子偏转方向和横向电场方向 |
| 线圈力矩、磁矩、做功 | 写 $\mathbf p_m=NIS\mathbf e_n$，再看 $\mathbf p_m\times\mathbf B$ |
| $\mu_r,\chi_m,\mathbf H,\mathbf M$ | 用介质中安培环路定理：$\oint\mathbf H\cdot\mathrm d\mathbf l=I_{0\text{内}}$ |

## 第一动作

读题后先写三行：

1. 源：谁产生磁场？电流元、长直电流、面电流、运动电荷，还是磁化电流？
2. 对象：题目要求场点的 $\mathbf B$，还是粒子/导线/线圈受力，还是介质里的 $\mathbf H$？
3. 方向：用右手定则或叉乘先定方向，再代数计算。

## 最小自测

1. 问：为什么闭合曲面的磁通量一定为零？  
   答案要点：磁感应线无头无尾，没有孤立磁单极；所以 $\oint_S\mathbf B\cdot\mathrm d\mathbf S=0$。

2. 问：什么时候安培环路定理能直接求 $B$？  
   答案要点：电流分布有足够对称性，能选出路径使 $B$ 大小恒定且与 $\mathrm d\mathbf l$ 夹角恒定或分段恒定。

3. 问：洛伦兹力会不会改变粒子速率？  
   答案要点：不会。磁场力始终垂直速度，不做功，只改变速度方向。

4. 问：介质题为什么常先求 $\mathbf H$？  
   答案要点：$\oint\mathbf H\cdot\mathrm d\mathbf l$ 只和传导电流代数和有关；求出 $\mathbf H$ 后再用 $\mathbf B=\mu\mathbf H$ 或 $\mathbf M=\chi_m\mathbf H$。

5. 问：载流闭合线圈在匀强磁场中一定会平动吗？  
   答案要点：不一定。匀强磁场中闭合线圈合力为零，但可受磁力矩转动。
