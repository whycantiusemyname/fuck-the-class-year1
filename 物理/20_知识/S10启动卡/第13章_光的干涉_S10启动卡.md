## 5 分钟地图

本章做题先抓四个词：**两束光、光程差、半波损失、条纹条件**。

- 两束光：双缝两束、薄膜上下表面反射两束、干涉仪两臂。
- 光程差：几何路程差 + 介质附加光程 + 往返光程。
- 半波损失：反射从低折射率到高折射率时多一个 $\pi$ 相位变。
- 条纹条件：明暗条件由 $\Delta$ 是整数倍还是半整数倍波长决定。

## 题型分流

| 题面信号 | 第一动作 |
| --- | --- |
| 介质板、相位差、光程 | 分别写两路光程 $L=\sum ns$ |
| ★教材打星：双缝、缝距、屏距、白光 | 写 $\Delta\approx dx/D$，再看级次 |
| 插玻璃片、云母片 | 写附加光程 $(n-1)e$，判断中央明纹移动 |
| 薄膜、增透膜、油膜 | 先判 $n_1,n_2,n_3$ 和半波损失 |
| 劈尖、金属丝、工件缺陷 | 写 $e=\theta x$，条纹间距来自 $\Delta e$ |
| 牛顿环、曲率半径 | 写 $e=r^2/(2R)$，优先用 $r^2$ 或直径平方差 |
| ★教材打星：迈克耳孙、条纹移动数 | 写光程差改变 $=N\lambda$，检查往返因子 2 |

## 第一动作

读题后先写四行：

1. 两束光：我比较哪两束？
2. 光程差：$\Delta$ 包含哪些几何段或介质段？
3. 半波损失：反射题中明暗条件是否要对调？
4. 几何关系：双缝用 $x/D$，劈尖用 $\theta x$，牛顿环用 $r^2/(2R)$，还是迈克耳孙用 $2d$？

## 最小自测

1. 问：为什么普通两个手电筒照在一起没有稳定干涉条纹？  
   答案要点：它们不是稳定相干光源，相位差不稳定。
2. 问：一路插入厚度 $e$、折射率 $n$ 的薄片，常见附加光程是多少？  
   答案要点：相对同厚度空气多 $(n-1)e$。
3. 问：薄膜反射题为什么不能只写 $2ne$？  
   答案要点：还要判断上下两束反射光是否有相对半波损失。
4. 问：空气劈尖条纹间距为什么和劈尖角成反比？  
   答案要点：$e\approx\theta x$，相邻同类条纹对应固定厚度差 $\lambda/(2n)$。
5. 问：迈克耳孙干涉仪镜子移动 $d$，为什么光程差改变是 $2d$？  
   答案要点：该臂光往返一次，路径长度改变两倍。
