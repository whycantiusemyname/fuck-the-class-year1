## 5 分钟地图

- 本章核心：用大量分子的统计平均解释压强、温度、内能和分布。
- 先分清层次：单个分子、单位体积、总分子数、1 mol、一定质量气体。
- 核心入口：$pV=NkT$、$\frac12m\overline{v^2}=\frac32kT$、$E=\frac{i}{2}\nu RT$、$\mathrm{d}N/N=f(v)\,\mathrm{d}v$。

## 题型分流

| 题面信号 | 第一动作 |
| --- | --- |
| 给 $p,V,T,N,n$ | 用状态方程换算分子数或数密度 |
| 问平均平动动能 | 用 $\frac32kT$，别当成总内能 |
| 问内能、自由度 | 判定 $i$，写 $E=\frac{i}{2}\nu RT$ |
| 给 $f(v)$ 或分布曲线 | 先判断要占比、分子数，还是区间平均 |
| 问大气压和高度 | 检查等温假设，用玻尔兹曼分布 |

## 第一动作

读题后写四行：

1. 对象层次：单个分子 / $N$ 个分子 / $1\ \mathrm{mol}$ / 质量 $M$？
2. 能量类型：平动动能 / 总动能 / 内能？
3. 分布问题：面积、人数、平均值，还是曲线比较？
4. 单位：温度用 K，压强用 Pa，体积用 $\mathrm{m^3}$。

## 最小自测

1. 问：$\overline{v_x}=0$ 是否表示分子不运动？  
   答案要点：不是；正负方向统计抵消，热运动强度看平方平均。
2. 问：$f(v)\,\mathrm{d}v$ 表示什么？  
   答案要点：速率在 $v$ 附近、宽度为 $\mathrm{d}v$ 的分子数占总数的比例。
3. 问：刚性双原子分子 $1\ \mathrm{mol}$ 理想气体内能是多少？  
   答案要点：取 $i=5$，内能 $E=\frac52RT$。
4. 问：同温下氦气和氮气谁的速率分布更靠右？  
   答案要点：氦气分子质量小，典型速率更大，曲线更靠右。
