## 5 分钟地图

本章做题先抓四个词：**孔径、暗纹、光栅级次、缺级**。

- 孔径：缝宽 $a$ 越小，中央明纹越宽。
- 暗纹：单缝暗纹用 $a\sin\theta=k\lambda$。
- 光栅级次：光栅主极大用 $d\sin\theta=k\lambda$。
- 缺级：光栅主极大若落在单缝暗纹方向，就看不见。

## 题型分流

| 题面信号 | 第一动作 |
| --- | --- |
| ★教材打星：单缝宽度、中央明纹宽度、暗纹 | 写 $a\sin\theta=k\lambda$，中央宽度看两侧第一级暗纹 |
| 半波带数、某角度明暗 | 写 $N=2a\sin\theta/\lambda$ |
| ★教材打星：每毫米多少刻线、最高级次 | 先换算光栅常数 $d$，再用 $|k|\le d/\lambda$ |
| ★教材打星：同时给缝宽 $a$ 和光栅常数 $d$ | 检查缺级 $k=m d/a$ |
| 白光、两波长谱线重合 | 写 $k_1\lambda_1=k_2\lambda_2$ |
| 分辨本领、卫星成像 | 区分角分辨和线分辨 |
| X 射线晶体 | 看角度是与晶面还是法线夹角，再用 $2d\sin\theta=k\lambda$ |

## 第一动作

读题后先写四行：

1. 装置：单缝、光栅、圆孔/透镜、还是晶体？
2. 尺度：$a,d,\lambda,f$ 的单位统一了吗？
3. 条件：暗纹、主极大、缺级、谱线重合，分别是哪一个？
4. 位置：需要从角度换到屏上距离吗？

## 最小自测

1. 问：单缝中央明纹为什么缝越窄越宽？  
   答案要点：第一级暗纹满足 $a\sin\theta=\lambda$，$a$ 变小则 $\theta$ 变大。
2. 问：光栅最高级次怎么判断？  
   答案要点：由 $d\sin\theta=k\lambda$ 和 $|\sin\theta|\le1$ 得 $|k|\le d/\lambda$。
3. 问：为什么有些光栅级次会缺失？  
   答案要点：该级主极大方向同时是单缝暗纹方向，被单缝包络压掉。
4. 问：两种波长谱线重合的条件是什么？  
   答案要点：同一角度下 $k_1\lambda_1=k_2\lambda_2$。
5. 问：卫星分辨率题为什么要乘以高度？  
   答案要点：衍射给的是角分辨，地面线分辨约为距离乘角度。
