# 第05章 波动学基础 S10启动卡

> 这是进入 S10 问答/做题前的启动卡，不替代 `主干讲解.md`。
> 完全没学过本章时，先读主干讲解；读过但准备做题时，再读这份。

## 5 分钟地图

本章只抓一条线：**振动状态沿空间传播，遇到另一列波时按相位叠加。**

- 一列波：先判传播方向，再写 $y(x,t)$。
- 图像题：波形图看空间，振动曲线看时间。
- 叠加题：先算到达点相位差。
- 驻波题：看空间振幅因子，找波节和波腹。
- 能量题：分清能量密度、强度、平均能流和总能量。
- 多普勒题：先画声源、观察者、波传播方向。

## 题型分流

| 题面信号 | 第一动作 |
| --- | --- |
| $t=0$ 波形图、传播方向、某点速度 | 想象波形沿传播方向平移，判断该点位移变大还是变小 |
| 某点振动方程、距离、波速 | 写传播延迟 $(x-x_0)/u$，再决定 $kx$ 符号 |
| 两个波源、路程差、相长/相消 | 把初相差和路程差都换成相位差 |
| 反射面、固定端、自由端、波节/波腹 | 先判断边界相位条件 |
| 强度、能流、能量密度、截面积、时间 | 先判断题目要的是 $I$、$\bar{w}$、功率还是总能量 |
| 汽笛、火车、观察者、拍频 | 先分别求两个接收频率，再取差 |

## 第一动作

读题后先写四行：

1. 图像类型：$y-x$ 还是 $y-t$？
2. 传播方向：沿 $+x$ 还是 $-x$？
3. 参考点：题目给的是哪个点的振动？
4. 入口：方程互推、能量、相干叠加、驻波还是多普勒？

## 最小自测

1. 问：$y=A\cos(\omega t-kx+\varphi)$ 表示沿哪个方向传播？  
   答案要点：沿 $+x$。令相位不变，$t$ 增大时 $x$ 也增大。
2. 问：波形图上某点速度方向怎么判？  
   答案要点：把整条波形按传播方向平移一点，看固定 $x$ 处位移变大还是变小。
3. 问：相干叠加题为什么不能只看路程差？  
   答案要点：还要加上两个波源本身的初相差。
4. 问：驻波和行波最重要的区别是什么？  
   答案要点：驻波没有整体向前传播的波形，空间各点振幅不同，有波节和波腹。
5. 问：行波能量题为什么不能套单个弹簧振子？  
   答案要点：波中质元能量随波传播，动能和弹性势能常同步变化，不是简单此消彼长。

## 提问入口

- 给我一道波形图题，我只判断速度方向。
- 给我一个点的振动方程，我写整列波方程。
- 给我两个相干波源，我只算相位差。
- 给我一个驻波方程，我读波节和波腹。
- 给我一道多普勒题，我先判断符号。
